### Task 18.5：项目服务实现（核心逻辑）

**文件**：`ruoyi-system/src/main/java/com/ruoyi/system/service/impl/FeeProjectServiceImpl.java`

```java
@Service @RequiredArgsConstructor
public class FeeProjectServiceImpl implements IFeeProjectService {
    private final FeeProjectMapper projectMapper;
    private final FeeProjectSubjectMapper subjectMapper;
    private final FeeProjectMemberMapper memberMapper;

    @Override
    @Transactional(rollbackFor = Exception.class)
    public int approveProject(Long id) {
        FeeProject project = projectMapper.selectById(id);
        // 1. 状态变更
        project.setStatus("ACTIVE");
        project.setCurrentContractAmount(project.getContractAmount());
        projectMapper.updateById(project);
        // 2. 从全局科目继承生成项目科目（如果未手动配置）
        if (subjectMapper.countByProjectId(id) == 0) {
            inheritGlobalSubjects(project);
        }
        // 3. 项目预算汇入对应大类
        mergeBudgetToCategory(project);
        // 4. 通知财务
        notifyFinanceProjectApproved(project);
        return 1;
    }

    @Override
    @Transactional(rollbackFor = Exception.class)
    public boolean deductBudget(Long projectId, Long categoryId, BigDecimal amount) {
        // 查询该大类下的项目科目余额
        List<FeeProjectSubject> subjects = subjectMapper.selectByProjectAndCategory(projectId, categoryId);
        BigDecimal totalAvailable = subjects.stream()
            .map(s -> s.getBudgetAmount().subtract(s.getUsedAmount()))
            .reduce(BigDecimal.ZERO, BigDecimal::add);
        if (totalAvailable.compareTo(amount) < 0) return false;
        // 按科目顺序扣减
        BigDecimal remaining = amount;
        for (FeeProjectSubject s : subjects) {
            BigDecimal avail = s.getBudgetAmount().subtract(s.getUsedAmount());
            if (avail.compareTo(BigDecimal.ZERO) <= 0) continue;
            BigDecimal deduct = remaining.min(avail);
            s.setUsedAmount(s.getUsedAmount().add(deduct));
            subjectMapper.updateById(s);
            remaining = remaining.subtract(deduct);
            if (remaining.compareTo(BigDecimal.ZERO) <= 0) break;
        }
        // 更新项目已用预算
        FeeProject project = projectMapper.selectById(projectId);
        project.setUsedBudget(project.getUsedBudget().add(amount));
        projectMapper.updateById(project);
        return true;
    }
}
```

### Task 20.2：三态核心逻辑

```
状态机：
  PENDING(待核验🟡) → VERIFIED(已核验✅) [财务核验通过]
  PENDING(待核验🟡) → REJECTED(已驳回❌) [财务核验驳回]

计入利润规则：
  - 仅 VERIFIED 状态计入项目利润
  - PENDING 只在项目经理待办中显示
  - REJECTED 不计入，需补据重提

创建来源：
  - 项目经理手动创建 → 状态 = PENDING
  - 收款单审核通过联动 → 状态 = VERIFIED（财务即核验人）
```

```java
@Transactional
public int approveChange(Long id) {
    FeeProjectChange change = changeMapper.selectById(id);
    FeeProject project = projectMapper.selectById(change.getProjectId());
    // 1. 合同额叠加（不回溯历史）
    project.setCurrentContractAmount(
        project.getCurrentContractAmount().add(change.getContractDelta()));
    project.setChangeCount(project.getChangeCount() + 1);
    projectMapper.updateById(project);
    // 2. 预算按大类追加
    Map<String, BigDecimal> deltas = JSON.parseObject(change.getBudgetDeltas(), Map.class);
    for (Map.Entry<String, BigDecimal> entry : deltas.entrySet()) {
        addProjectBudget(project.getId(), entry.getKey(), entry.getValue());
    }
    // 3. 状态 = 待收款确认
    change.setChangeStatus("CONFIRMED");
    changeMapper.updateById(change);
    // 4. 生成变更记录（不可删）
    return 1;
}
```

```java
public int markBadDebt(Long projectId, FeeBadDebtBo bo) {
    // 1. 创建烂账记录
    FeeBadDebt debt = MapstructUtils.convert(bo, FeeBadDebt.class);
    debt.setProjectId(projectId);
    debt.setMarkedBy(LoginHelper.getUserId());
    debt.setStatus("OPEN");
    badDebtMapper.insert(debt);
    // 2. 项目状态变为 LOST
    FeeProject project = projectMapper.selectById(projectId);
    project.setStatus("LOST");
    project.setLossType(bo.getType());
    project.setLossReason(bo.getReason());
    project.setBadDebtProvision(bo.getProvisionAmount());
    projectMapper.updateById(project);
    // 3. 计提坏账影响利润（如有）
    if (bo.getProvisionAmount() != null && bo.getProvisionAmount().compareTo(BigDecimal.ZERO) > 0) {
        project.setTotalExpense(project.getTotalExpense().add(bo.getProvisionAmount()));
        projectMapper.updateById(project);
    }
    return 1;
}
```

### Task 24.3：后补通道核心逻辑

```

  有发票 → 正常通道（OCR验真→匹配→审批）
  无发票 → 后补通道：
    1. 勾选"发票后补" + 选预计补票日期（默认7天）
    2. 财务审核时必须填审核理由
    3. 一律需老板审批
    4. 审批通过 → 大类额度预占（"已承诺未核销"）

    6. 超时未补 → 预占释放 + 标记异常

信用分规则：
  按时补票 +2分
  逾期 -5分
  连续3次按时 +10分奖励
  <50分 → 禁止无发票报销

信用等级：
  ≥80分(优秀) → 免老板审批，补票期限14天
  50-79分(正常) → 正常流程，7天期限
  <50分(受限) → 禁止无发票报销
```

### Task 27.2：利润计算公式

```
项目利润 = 已核验收入 - 报销/付款支出 - 折旧分摊 - 项目分成

公司总支出 = 所有项目支出 + 公司级人力成本 + 公司级折旧 + 利息 + 手续费

老板看板：

纸面利润 = 合同额 - (已核验+待核验收入) - 支出  [含未到账]
实际利润 = 已核验收入 - 支出                     [仅财务确认过的]
```
