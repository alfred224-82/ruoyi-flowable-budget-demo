# 预算编制管控系统 · UI 设计文档

> 本文档面向设计师与前端开发，定义**每个角色在每个端**能看到的页面、菜单、核心信息密度与交互要点。
> 双端策略：**PC 管理后台（Vue3）做"能耐住性子做的事"**，**微信小程序（uni-app）做"3 秒看全、5 秒决策"**。
> 配套文档：《架构决策清单 ADR》（硬约束）、《预算编制管控系统产品方案.md》（产品逻辑）、《预算编制管控系统_技术文档.md》（开发落地）。

---

## 〇、双端分工总览

| 维度 | PC 管理后台（Vue3 + Element Plus） | 微信小程序（uni-app） |
|------|-----------------------------------|----------------------|
| **定位** | "能耐住性子做的事"：编制、配置、审核、导出、管理 | "3 秒看全、5 秒决策"：看板、确认、提交、审批 |
| **用户** | 财务（主力）、老板（看板+审批）、项目经理（收入确认） | 老板（看板）、项目经理（收入+项目）、报销人（提交） |
| **核心交互** | 表单填写、列表多选、批量操作、下钻、配置页 | 卡片、进度条、单选、底部弹窗、长按菜单 |
| **信息密度** | 高（多列表、多列、可滚动） | 低（每屏 1 个核心决策点） |
| **主要页面** | 15+ 个管理页 | 8 个核心页 + 弹窗 |
| **导航方式** | 左侧菜单 + 顶栏 | 底部 Tab Bar + 顶部导航 |

**设计原则**：PC 追求"功能完整、操作顺手"；小程序追求"一屏一决策、最少点击"。同一份数据，PC 展开所有字段和筛选，小程序只露关键指标。

### 1.2 各菜单页说明

#### 1.2.1 预算编制

| 页面 | 核心内容 | 关键元素 |
|------|---------|---------|
| **本月预算** | 大类额度编辑（老板定总额→财务微调） | 大类卡片/进度条、编辑按钮、锁定状态 |
| **预算明细** | 大类→预算科目→金额，可增删改 | 树形表格、加减行、合计行 |
| **调整申请** | 提交预算调整→老板审批列表 | 申请表单、审批状态筛选 |

#### 1.2.2 报销管理

| 页面 | 核心内容 | 关键元素 |
|------|---------|---------|
| **报销列表** | 全部报销单（筛选：状态/大类/项目/申请人） | 表格+筛选栏+批量操作 |
| **新建报销** | 填报销单（选大类→填金额→★选项目→传发票/后补） | 分步表单、项目下拉、发票上传、后补开关 |
| **付款单** | 对外付款（必选项目+必选老板批） | 比报销单多：付款方/收款方/付款类型 |
| **收款单** | 收回钱（必选项目） | 比报销单多：付款方/收款类型 |
| **烂账管理** | 标记风险/烂账项目列表 | 风险类型、处理方案、计提金额 |

#### 1.2.3 项目模块

| 页面 | 核心内容 | 关键元素 |
|------|---------|---------|
| **项目列表** | 所有项目卡片/表格（状态筛选） | 项目卡片网格、状态标签、利润速览 |
| **项目详情** | 下钻：合同→预算→收支时间线→成员→分成→利润拆解 | 多 Tab 切换、时间线组件、利润公式展示 |
| **新建项目** | 立项表单（项目名称/客户/合同额/周期/预算按大类分配） | 表单+行业模板下拉+预算分配器 |
| **项目成员** | 添加/管理成员（显示该成员在其他项目的负载） | 成员表格、角色设置、负载标签 |
| **收入确认** | 收入确认列表（三态筛选：待核验/已核验/已驳回）+ 新建 | 状态标签、依据编号可点开附件、批量操作 |
| **合同变更** | 变更单列表（状态筛选）+ 发起变更单 | 变更单卡片、状态进度、delta 展示 |
| **分成管理** | 项目分成配置（按对象/比例/基数）+ 结算记录 | 分成对象表格、比例编辑、结算按钮 |
| **资产折旧** | 资产清单（增删改）+ 折旧设置 | 资产表格、归属项目设置、折旧率计算 |

#### 1.2.4 财务管理

| 页面 | 核心内容 | 关键元素 |
|------|---------|---------|
| **凭证导出** | 选月+选模板+选范围→下载 Excel | 三因子选择器、模板下拉（7套内置） |
| **科目映射** | 费用科目→预算科目→大类的映射规则 | 三层映射表格、关键词别名库、自动匹配开关 |
| **发票验真** | 发票查验结果列表 | 查验状态、金额比对、异常标记 |
| **团队配置** | 用户角色分配、信用规则配置、项目关联规则 | 用户表格（角色下拉）、信用分规则、规则开关 |

#### 1.2.5 系统设置

| 页面 | 核心内容 | 可操作角色 |
|------|---------|-----------|
| **通知设置** | 微信订阅消息模板开关（审批提醒/预警/逾期） | 老板+财务 |
| **数据导出** | 全量数据导出（Excel/CSV） | 财务+老板 |
| **日志审计** | 操作日志（谁在什么时间改了什么） | 财务+老板 |
| **薪资与社保设置**（新增） | 员工薪资标准录入、社保/公积金比例、自动计提开关 | 老板设+财务维护 |
| **分成规则模板**（新增） | 公司级默认分成比例、默认基数类型、常见角色预设 | 老板 |
| **资产折旧规则**（新增） | 资产分类标准（电子设备3年/车辆5年等）、折旧方法 | 财务 |
| **利息/费率设置**（新增） | 贷款参数（金额/利率/还款方式）、平台手续费率、税率 | 财务 |

### 2.2 各 Tab 页面说明

#### Tab 1：🅰 大类看板（老板主力页）

| 页面 | 内容 | 交互 |
|------|------|------|
| 大类总览 | 6 张大类卡片（进度条+状态色），超支标红 | 点击下钻 |
| 项目下钻 | 点大类卡 → 该类下所有预算科目进度 | 再点科目→报销明细 |
| 项目 Tab | 点"查看项目"入口 → 跳转项目页 | 滑动切换 |

## 四、核心信息密度规范

| 端 | 每屏最大决策点 | 每屏最大数据行 | 滚动方式 |
|----|--------------|--------------|---------|
| PC | 不限（多面板） | 50+（虚拟滚动） | 页面内滚动 |
| 小程序 | **1个** | **3-5行** | 整页切换（非滚动） |

**小程序铁律**：一个页面只解决一个决策。需要看更多 → 点进去（新页面）。PC 可以"一屏全览"，小程序"一屏一决策"。
