# 预算编制管控系统 · 发布成本与后续方案

> **版本**：v1.0
> **配套文档**：《架构决策清单》《完整产品方案》《技术文档》《UI设计文档》
> **重要约定**：本文档区分两类成本——
> - **部署成本**：服务器、域名、备案、认证等**上线运维的钱**（第二、三章）
> - **模块成本**：实现某个功能要花多少人力（第四~七章）
>
> **隐形成本（分成/折旧/工资社保/利息）本身是"系统功能"**——配置入口、计提规则、利润公式，详见《完整产品方案》对应章节与《UI设计文档》。本文档只在第七章说明"实现这些功能的人力成本"，**绝不把功能描述和部署花钱混在一起**。

---

## 一、定价与目标客户

- 目标：约50人小公司，老板 + 会计 + 员工
- 基础版 299/月（年付2990，相当于10个月）
- 高级版 599-799/月（打卡/防作弊/项目利润报表）
- 专业版 999-1499/月（人脸/多组织/二维导出）
- 盈亏平衡：单个客户年付 2990 元即覆盖全部运维成本

## 二、MVP 发布成本（部署/运维成本）

### 2.1 一次性投入（上线首月）

| 项目 | 费用 | 说明 |
|------|------|------|
| 腾讯云轻量服务器（已有则0） | 0~500 | 跑 Spring Boot + MySQL + Redis |
| 域名注册（.cn 首年） | 33 | **付费，按年续费 38/年** |
| ICP 备案 | 0 | 腾讯云免费代提交，企业主体7~10工作日 |
| DV SSL 证书 | 0 | 腾讯云免费申领，1年有效 |
| COS 对象存储 | <50 | 发票/合同/照片 |
| 微信小程序认证（企业） | 300 | 微信官方收，首次上线必交 |
| **合计（常见场景）** | **≈300~633** | 见下方三种场景 |

**三种场景：**
- **域名+服务器都已持有**（最常见）：≈ **300 元**（仅小程序认证）
- **域名需新注册**：≈ **333 元**
- **域名+服务器均新购**：≈ **633~783 元**

### 2.2 年度固定成本（稳态）

| 项目 | 年费 |
|------|------|
| 域名续费（.cn） | 38 |
| 小程序认证 | 300 |
| SSL 证书 | 0（免费续） |
| COS | <50 |
| 服务器（若按年包） | 另摊 300~500，或已有则0 |
| **合计（已有服务器前提下）** | **≈ 338~390 元/年** |

> ⚠️ 修正旧文"小程序年成本≈300元"：300元仅为微信认证，**不含域名续费**。完整年运维 = 域名续费 + 认证 + SSL(0) + COS(<50) ≈ **338~390 元/年**。

### 2.3 盈亏平衡

- 单客户年付 2990 元 >> 年运维 338~390 元
- **盈亏平衡 = 1 个客户**（前20位可送"费用体检"引流）

## 三、腾讯云配套详解（部署成本）

### 3.1 腾讯云对小程序/后端的帮助（全匹配）

| 能力 | 腾讯云产品 | 用途 |
|------|-----------|------|
| 后端部署 | CVM / 轻量应用服务器 | 跑 Spring Boot Jar |
| 数据库 | 云数据库 MySQL | 多租户 tenant_id 隔离 |
| 缓存 | 云数据库 Redis | 映射规则/额度/access_token |
| 静态/发票 | COS 对象存储 | 发票照片/合同（低频，<50/年） |
| 域名+HTTPS | DNSPod + 免费 DV SSL | 小程序强制 HTTPS |
| 备案 | 免费备案通道 | 大陆节点必备案，腾讯云代提交 |
| 微信生态 | 同属腾讯，延迟低 | wx.login / 订阅消息更稳 |

**结论**：已有腾讯云空间 = 后端部署/存储/域名/备案/HTTPS 一条龙，与 Java 技术栈完全匹配，不用换云。

### 3.2 费用明细（什么付费/免费）

| 项目 | 付费？ | 费用 |
|------|--------|------|
| 域名注册（.cn/.com） | **付费** | 首年33~83，续费38~90/年 |
| ICP 备案 | **免费** | 腾讯云+管局均不收费 |
| DV SSL 证书 | **免费** | 腾讯云免费申领 |
| 服务器/DB/Redis | 已有则0，新购另计 | 轻量2核4G ≈300~500/年 |
| COS | 按量，初期极低 | <50/年 |
| 微信小程序认证 | 付费 | 300/年（官方收） |

### 3.3 部署 Checklist

1. 注册/持有域名（.cn 或 .com）
2. 域名 ICP 备案（企业主体，**7~10工作日，务必提前**）
3. 申请免费 DV SSL，配置 HTTPS
4. 开通轻量服务器 + MySQL + Redis（已有则复用）
5. 开通 COS 存发票照片
6. 微信公众平台注册小程序，企业认证（300元/年）
7. 配置小程序合法域名 = `https://api.yourdomain.com`
8. 后端部署 Jar，验证 wx.login → JWT → tenant_id 隔离
9. 定时任务（薪资/折旧/利息计提）上 cron

> **备案是长周期项（最长20天），应最先启动**，与开发并行。

## 七、隐形成本成本归属（仅算人力，功能见产品方案）

> **本章定位**：隐形成本是"系统功能"（分成三层配置/折旧公式/工资社保方案A/利息费率/利润公式），完整功能描述在《完整产品方案》第十三章与《UI设计文档》第三章（薪资社保页/资产折旧页/分成页/利息页）。
> **本章只算"实现这些功能要花多少人力 + 对发布成本的影响"。部署/运维的钱（服务器、域名、备案、认证）始终只在第二、三章，绝不混进功能描述。**

| 隐形成本模块 | 实现人力 | 归属/权限（ADR） | 是否加钱 |
|-------------|---------|-----------------|---------|
| 项目分成（三层配置+结算调整） | 3 人天 | 老板定比例（ADR-025） | 否（纯逻辑） |
| 资产折旧（规则设置+自动计提） | 2 人天 | 财务设规则（ADR-026） | 否 |
| 工资社保（方案A+每月计提） | 2 人天 | 老板设标准/财务维护（ADR-024） | 否 |
| 利息/手续费/税费 | 1 人天 | 财务设参数（ADR-027） | 否 |
| 利润公式 + 老板看板固定成本卡片 | 2 人天 | — | 否 |
| **合计** | **≈ 10 人天** | | **仅加人力，不加钱** |

**关键结论**：隐形成本模块**只加人力（≈10人天）、不加钱**——纯后端逻辑 + 定时任务，不新增服务器/域名/备案支出。所以**绝不能和服务器/域名混在一起算**（这也是把"功能"与"部署成本"分开的原因）。

## 九、上线路径

1. **准备（并行）**：备案（最先，7~20天）、域名、小程序注册认证
2. **MVP 开发（8周）**：核心闭环（编制→报销→看板→导出）
3. **种子验证**：前10个客户免费做"费用体检"，验证核心闭环
4. **正式发布**：定价 299/月，主打"会计不用多学，月末导Excel进金蝶"
5. **迭代**：项目模块 → 隐形成本 → 防假账 → 组织架构 → 多组织

## 一句话总结

**首年现金成本 ≈ 300 元（小程序认证，域名已持有时），年运维 ≈ 338~390 元，盈亏平衡仅需 1 个客户。**
**功能层面（项目模块 + 隐形成本 + 防假账 + 凭证导出）只加人力、不加钱——纯后端逻辑与定时任务，不新增任何基础设施支出。**
**架构上：单域名 + JWT tenant_id 逻辑隔离多租户（M-2、M-3），第二家公司入驻 = 建 tenant + 复制模板，分钟级完成，不需要新服务器/新域名/重新备案。**
