## T9.1 零迁移升级演练（P0）

> 目标：基础版→高级版→专业版完整演练，验证全程无数据结构变更、无数据丢失

### 升级演练步骤

- [ ] **1. 环境准备**
  - [ ] 备份生产数据库（mysqldump 全量备份）
  - [ ] 确认当前版本等级（`SELECT edition FROM sys_tenant LIMIT 1`）
  - [ ] 记录当前菜单总数（`SELECT COUNT(*) FROM sys_menu`）
  - [ ] 记录当前角色-菜单关联数（`SELECT COUNT(*) FROM sys_role_menu`）

- [ ] **2. 基础版→高级版升级**
  - [ ] 修改目标租户 `sys_tenant.edition` = 'ADVANCED'
  - [ ] 执行 M3_05（License 租户关联改造，若未执行）
  - [ ] 执行 M3_06（License 管理菜单增强）
  - [ ] 复制高级版菜单模板（`PLATFORM_ADMIN_ADVANCED` → 租户角色菜单）
  - [ ] 导入高级版 License（通过 License 管理页面）
  - [ ] 重启应用
  - [ ] 验证：高级版菜单可见（3217~3223、按钮 3241~3248/3291~3297）
  - [ ] 验证：高级版功能接口可访问（信用分、打卡、利润报表等）
  - [ ] 验证：基础版数据完整无损（项目/报销/预算数据正常）

- [ ] **3. 高级版→专业版升级**
  - [ ] 修改目标租户 `sys_tenant.edition` = 'PROFESSIONAL'
  - [ ] 复制专业版菜单模板（`PLATFORM_ADMIN_PROFESSIONAL` → 租户角色菜单）
  - [ ] 导入专业版 License
  - [ ] 重启应用
  - [ ] 验证：专业版菜单可见（3224~3226、按钮 3249/3250/3294/3295/3298/3299）
  - [ ] 验证：专业版功能接口可访问（多组织、人脸、二维导出等）
  - [ ] 验证：高级版历史数据完整保留

- [ ] **4. 数据完整性复核**
  - [ ] 全表记录数与升级前一致
  - [ ] 无新增表结构变更（对比 `SHOW CREATE TABLE` 输出）
  - [ ] `sys_tenant_version_log` 有 INIT → UPGRADE 记录
  - [ ] 操作日志 `sys_oper_log` 有版本变更记录

## T9.3 到期/降级场景验证（P1）

> 目标：到期禁用、降级后高版本入口消失且历史数据保留

### 到期场景

- [ ] **1. 租户到期 → 禁止登录**
  - [ ] 设置租户到期日为昨天
  - [ ] 等待 `tenantExpireCheckJob` 执行（或手动触发）
  - [ ] 验证：租户状态变为 EXPIRED
  - [ ] 验证：租户用户登录被拒绝，提示"租户授权已到期"
  - [ ] 验证：已登录会话访问业务接口被拦截

- [ ] **2. License 到期 → 功能降级**
  - [ ] 设置租户 License 到期日为昨天
  - [ ] 等待被动检测触发（访问任意业务接口）
  - [ ] 验证：License 状态变为 EXPIRED
  - [ ] 验证：`/system/edition/features` 返回 BASIC 功能集
  - [ ] 验证：高级/专业版接口被 `@RequireFeature` 拦截
  - [ ] 验证：租户状态仍为 NORMAL（仅功能降级，不禁登录）

### 降级场景

- [ ] **3. 专业版→基础版降级**
  - [ ] 将租户 edition 改为 BASIC
  - [ ] 验证：高版本菜单从角色菜单中移除
  - [ ] 验证：前端高版本入口消失（`/system/edition/features` 返回基础版）
  - [ ] 验证：历史数据（项目/报销/预算）完整保留
  - [ ] 验证：`sys_tenant_version_log` 有 DOWNGRADE 记录

- [ ] **4. 管理员延长到期日 → 自动恢复**
  - [ ] 将已到期租户的 expire_date 延长至明天
  - [ ] 验证：租户状态自动恢复为 NORMAL
  - [ ] 验证：用户可正常登录和访问

