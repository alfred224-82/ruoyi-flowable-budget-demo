# 预算编制管控系统 · UI 设计文档

> **版本**：v1.0
> **配套文档**：《架构决策清单》《完整产品方案》《技术文档》

---

## 一、双端分工

| 端 | 技术栈 | 用户 | 基调 |
|----|--------|------|------|
| PC 管理后台 | Vue3 + Element Plus | 财务/管理员 | 信息密度高、表格为主 |
| 微信小程序 | uni-app | 老板/项目经理/报销人 | 卡片化、3秒看全 |

**PC 做"能耐住性子做的事"，小程序做"3秒看全、5秒决策"。**

---

## 二、角色 × 端 × 页面

| 角色 | PC 端 | 小程序端 |
|------|-------|---------|
| 老板 | 全局看板（可选） | 老板看板（总览/大类/项目）、审批、预警、立项 |
| 财务 | 工作台/编制/映射/审核/导出/设置 | 审批通知、预警查看 |
| 报销人 | 无 | 发起报销、我的报销、审批进度 |
| 项目经理 | 项目列表/详情/收入/变更/分成/成员 | 我的项目、收入确认、发起报销、分成查看 |

## 三、PC 管理后台

```
│    └── 自动匹配规则
├── 🧾 报销管理
│    ├── 报销审核
│    ├── 待核销池
│    └── 报销追溯

│    ├── 折旧记录
```

### 3.2 关键页面

**映射管理页**：费用科目 | 匹配方式 | 预算科目 | 状态，支持草稿→发布+影响分析。

**预算编制页**：大类 | 总额度 | 系统初稿 | 调整后 | 差异，步骤 ①初稿→②微调→③老板确认。

**报销审核页**：报销人 | 大类 | 金额 | 项目 | 匹配状态，支持批量通过/打回，未归类标记。

### 3.3 隐形成本相关页面（ADR-024~027）

**资产折旧页**：
```
资产清单：[+ 新增资产]
  名称 | 类别 | 原值 | 残值 | 年限 | 月折旧 | 已折 | 净值 | 归属
  MacBook | 电子设备 | 15000 | 1500 | 3年 | 375 | 3000 | 12000 | 客户A(60%)+公司(40%)
[折旧记录 Tab] [分摊设置 Tab]
```

**项目分成页**：
```
项目分成管理：
  项目 | 分成对象 | 角色 | 基数类型 | 比例 | 封顶 | 状态 | 操作
  客户A | 张三 | 执行合伙人 | 项目利润 | 35% | 无 | 待结算 | 编辑/结算
  客户A | 渠道商 | 渠道 | 合同额 | 10% | 无 | 已支付 | 查看
```

**薪资与社保页（3.4）**：
```

  [薪资标准] [社保公积金] [计提记录]

薪资标准 Tab：
  员工 | 月薪 | 社保(公司部分) | 所属项目 | 状态

  李四 | 9000  | 2400 | 公司级 | 在职
```

**利息/费率页**：
```
利息与费率设置：
  贷款利息：本金 / 年利率 / 还款方式 / 每月计提额
  平台手续费：类型(微信/支付宝/美团) / 费率% / 计提方式
  税费：增值税率 / 附加税率 / 计提方式
  [全部按月自动计提，老板只读]
```

### 3.4 设置项权限分区

| 专区 | 可见角色 | 内容 |
|------|---------|------|
| **老板专区** | 老板 | 分成规则模板、项目分成配置、项目关联规则、预警阈值、审批流 |
| **财务专区** | 财务（老板可看） | 薪资社保标准、资产折旧规则/清单、利息费率、税率、凭证模板 |
| **管理员专区** | ADMIN | 用户/角色、租户、系统参数 |

## 四、微信小程序端

**项目 Tab（含公司级成本，方案A）**：


### 4.3 项目经理页面

**我的项目**：进行中/已完成列表，每项含进度/剩余预算/成员。

**收入确认页**：
```
确认收入 - 客户A
  合同总额：130,000
  已确认：80,000（已核验 60,000 + 待核验 20,000）
  本次确认：____
  依据类型：○合同节点 ○开票 ○收款到账
  附件：[📎 上传]
  [提交审批]  → 状态：待核验 → 财务核验 → 已核验
```

**分成查看页**：我的项目分成（预计/已结算）。

### 4.4 报销人页面

**发起报销**：选大类 → 填金额 → 关联项目（选填，差旅提示）→ 描述 → 发票(可选,可后补) → 打卡(触发) → 提交。

**我的报销**：全部/待审/已通过/已驳回/后补中，支持补传发票。
