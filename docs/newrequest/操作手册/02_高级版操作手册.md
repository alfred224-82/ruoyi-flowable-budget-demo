## 二、高级版增量功能测试

### 2.1 打卡定位（FEAT_TIME_CLOCK）

**功能定位**：防假账辅助（威慑非定罪），报销提交时按规则触发定位+拍照

#### 2.1.1 打卡触发规则配置

**操作角色**：财务（finance01登录）  
**操作路径**：费用管控 → 打卡配置 → 新增

**内置默认规则**（tenant_id=0模板）：
| 规则编码 | 规则名称 | 触发条件 |
|---------|---------|---------|
| TRAVEL_CATEGORY | 差旅/招待大类触发 | 大类=差旅/招待 |
| AMOUNT_THRESHOLD | 单笔金额阈值触发 | 金额≥500 |
| HISTORY_ABNORMAL | 历史异常次数触发 | 历史异常≥2次 |

**自定义规则示例**：
1. 点击"新增"按钮
2. 输入规则编码：CUSTOM_AMOUNT
3. 输入规则名称：自定义金额阈值
4. 输入阈值：1000（金额≥1000触发）
5. 点击"保存"

**验收检查**：
```sql
-- 查看打卡触发规则
SELECT rule_code, rule_name, threshold, category_scope, is_enabled
 FROM fee_clock_trigger_rule
 WHERE tenant_id = <租户ID>;
-- 预期：包含内置3条+自定义1条
```

#### 2.2.2 信用分计算（定时任务）

**系统自动执行**：
- creditScoreCalcJob每周一02:00执行
- 遍历租户下所有员工
- 根据补票记录计算信用分
- 更新信用等级（≥80优秀，50-79正常，<50受限）

**手动触发测试**：
1. 登录XXL-JOB管理中心
2. 找到creditScoreCalcJob → 点击"执行一次"
3. 查看执行日志

**验收检查**：
```sql

 WHERE tenant_id = <租户ID>;
-- 预期：所有员工初始100分，根据补票记录调整

-- 信用等级映射
-- ≥80分：EXCELLENT（优秀）→ 免老板审批，补票期限14天
-- 50-79分：NORMAL（正常）→ 标准流程，7天期限
-- <50分：RESTRICTED（受限）→ 禁止无发票报销
```

### 2.5 项目利润报表（FEAT_PROFIT_REPORT）

**功能定位**：纸面利润 vs 实际利润分离，利润拆解，收支时间线

#### 2.5.1 项目利润报表查看

**操作角色**：财务/老板（finance01/boss01登录）  
**操作路径**：费用管控 → 项目利润报表

**界面内容**：
- 项目列表（项目名称、合同额、已核验收入、总支出、纸面利润、实际利润）
- 点击"详情"查看利润拆解

**利润计算公式**：
- **纸面利润** = 合同额 - (已核验+待核验收入) - 支出
- **实际利润** = 已核验收入 - 支出
- **利润拆解** = 已核验收入 - 报销/付款 - 折旧分摊 - 项目分成

**验收检查**：
```sql
-- 查看项目利润数据
SELECT p.project_name, p.current_contract_amount, p.verified_income,
 p.total_expense,
 (p.current_contract_amount - p.verified_income - p.total_expense) AS paper_profit,
 (p.verified_income - p.total_expense) AS actual_profit
 FROM fee_project p
 WHERE p.tenant_id = <租户ID> AND p.status = 'ACTIVE';
```

## 五、常见问题与排查

### 5.1 打卡定位失败

**现象**：报销提交时定位失败或无法获取位置

**排查步骤**：
1. 检查小程序是否授权定位权限
2. 检查手机GPS是否开启
3. 查看小程序日志

**解决方案**：
- 引导用户在手机设置中授权小程序定位权限
- 如仍失败，可跳过打卡（不阻断主流程，仅标记evidence_level=weak）

### 5.2 信用分未更新

**现象**：手动触发creditScoreCalcJob后信用分未变化

**排查步骤**：
1. 检查租户版本是否为高级版+
2. 检查补票记录是否存在
3. 查看任务执行日志

**解决方案**：
```sql
-- 检查租户版本
SELECT edition FROM sys_tenant WHERE id = <租户ID>;
-- 预期：ADVANCED或PROFESSIONAL

-- 检查补票记录
SELECT bill_id, status, supplement_date, estimated_date
 FROM fee_invoice_supplement
 WHERE tenant_id = <租户ID>;

-- 检查信用分记录
SELECT * FROM fee_employee_credit WHERE tenant_id = <租户ID>;
-- 如无记录，系统自动创建初始记录（默认100分）
```

### 5.3 部门预算编制后报销未扣部门额度

**现象**：部门预算已编制，但报销后部门额度未减少

**排查步骤**：
1. 检查报销人是否属于该部门
2. 检查部门预算是否已锁定
3. 检查dept_budget_deducted字段

**解决方案**：
```sql
-- 检查用户部门
SELECT u.user_id, u.user_name, u.dept_id, d.dept_name
 FROM sys_user u
 LEFT JOIN sys_dept d ON u.dept_id = d.dept_id
 WHERE u.user_id = <报销人user_id>;

-- 检查部门预算
SELECT department_id, category_name, used_amount
 FROM budget_detail
 WHERE preparation_id = <编制ID> AND department_id = <部门ID>;

-- 检查报销单标记
SELECT dept_budget_deducted FROM fee_expense_bill WHERE id = <报销单ID>;
-- 预期：dept_budget_deducted=1
```
