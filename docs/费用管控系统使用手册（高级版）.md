## 1. 系统概述与版本能力

### 1.1 高级版定位

高级版面向中型企业，在基础版编审闭环之上，扩展**可配置多级审批、AI智能填报、映射规则自动匹配、部门级资金池**等能力，满足多部门协作与精细化费用管控需求。

### 1.2 高级版核心特征

| 特征 | 说明 |
|------|------|
| 审批模式 | 可配置1~N级审批（基于Flowable工作流） |
| 资金池 | 部门级单层资金池 |
| 费用确认方式 | 直接费用化 + 折旧 + 计提摊销 |
| 风控规则 | WARNING级 + 规则可自定义 |
| 通知方式 | 审批结果通知 + 编制截止提醒 |
| AI能力 | AI对话式填报 |
| 数据范围 | 多部门 |
| 批量操作 | 支持批量提交/审批 |
| 报表分析 | 不支持（企业版专属） |
| 跨部门分摊 | 不支持（企业版专属） |

### 1.3 相比基础版新增能力

| 新增能力 | 说明 |
|---------|------|
| 可配置审批流 | 支持1~N级审批，基于Flowable引擎 |
| AI对话填报 | 9步AI引导式报销填报 |
| 映射规则 | 物资小类+用途标签自动匹配预算科目 |
| 用途标签 | 标记费用用途，触发映射规则 |
| 成本中心 | 费用归集管理 |
| 多币种 | 支持CNY/USD/EUR等币种报销 |
| 折旧/摊销 | 固定资产折旧、长期待摊费用摊销 |
| 超预算审批 | 独立的超预算审批流程 |
| 部门资金池 | 部门级预算调整资金管控 |
| 操作日志 | 全操作留痕 |
| 批量审批 | 支持勾选多条一键通过 |
| 编制期管控 | 编制截止时间提醒 |

### 1.4 与其他版本对比

| 能力维度 | 基础版 | 高级版 | 企业专业版 |
|---------|--------|--------|-----------|
| 审批层级 | 固定单级 | 1~N级可配 | 三级审批 |
| 资金池 | 无 | 部门级单层 | 三级资金池 |
| 费用确认方式 | 仅直接费用化 | 折旧+摊销 | 完整四轨 |
| 跨部门分摊 | 不支持 | 不支持 | 支持 |
| 报表分析 | 不支持 | 不支持 | 盈利分析+异常监控 |
| AI能力 | 不支持 | AI对话填报 | AI私有化+智能摘要 |
| 预算审批 | 单级 | 多级可配 | 完整三级 |

### 1.5 角色体系

高级版支持灵活的多级角色配置：

| 角色标识 | 角色名称 | 职责 |
|---------|---------|------|
| `deptPlan` | 部门预算编制人员 | 编制预算、提交报销、申请预算调整 |
| `deptManager` | 部门经理 | 第1级审批，管理本部门资金池 |
| 自定义角色 | 如：财务总监 | 第2~N级审批（按工作流配置） |

> **说明：** 高级版审批层级可自由配置，角色名称和级数由企业自行定义。

### 1.6 核心业务主线

```
系统初始化 → 预算编制 → 费用管控 → 预算调整
```

## 2. 租户与多租户管理

### 2.1 多租户模式说明

本系统采用 **SaaS 多租户架构**，支持多家企业（租户）共享同一套系统部署，各租户之间数据完全隔离。

**核心机制：**
- 每个企业作为一个独立「租户」接入系统
- 所有业务数据（预算、报销、科目、映射规则、福利政策等）通过 `tenant_id` 字段实现行级隔离
- 租户A的用户无法看到或操作租户B的任何数据
- 超级管理员（admin）不受租户隔离限制，可跨租户管理

### 2.2 租户信息

每个租户包含以下基本信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 租户编码 | 唯一标识（不可修改） | T0001 |
| 企业名称 | 公司全称 | XX科技有限公司 |
| 联系人 | 业务对接人 | 张三 |
| 联系电话 | — | 138xxxx0001 |
| 行业 | 所属行业 | 制造业 |
| 分配版本 | BASIC/ADVANCED/ENTERPRISE | ADVANCED |
| 授权类型 | TRIAL（试用）/FORMAL（正式） | FORMAL |
| 授权到期日 | 授权有效期 | 2027-12-31 |
| 最大用户数 | 允许创建的用户上限 | 50 |
| 状态 | PENDING/NORMAL/DISABLED/EXPIRED | NORMAL |

### 2.3 租户生命周期

```
PENDING（待激活）→ NORMAL（正常使用）→ DISABLED（已停用）
                                      → EXPIRED（已过期）
```

| 状态 | 说明 |
|------|------|
| PENDING | 租户已创建，尚未激活使用 |
| NORMAL | 正常使用中 |
| DISABLED | 平台管理员手动停用，所有用户无法登录 |
| EXPIRED | 授权到期，系统自动标记 |

### 2.4 租户管理员操作（平台管理员）

租户管理功能仅对拥有 `platform_admin` 角色的平台管理员可见。

**操作路径：** 系统管理 → 租户管理 → 租户列表

#### 2.4.1 创建租户

1. 进入「租户管理 → 租户列表」
2. 点击「新增」
3. 填写租户信息：
   - 租户编码（唯一，如：T0002）
   - 企业名称
   - 联系人、联系电话
   - 选择行业
   - 选择分配版本（基础版/高级版/企业版）
   - 设置授权类型（试用/正式）
   - 设置授权到期日
   - 设置最大用户数
4. 点击「确定」
5. 系统自动：
   - 创建租户管理员账号
   - 初始化默认角色
   - 记录版本分配日志

#### 2.4.2 启用/停用租户

1. 在租户列表找到目标租户
2. 点击「状态」开关
3. 停用后，该租户所有用户将无法登录系统
4. 重新启用后恢复正常

#### 2.4.3 版本分配与升级

1. 在租户列表点击「分配版本」
2. 选择目标版本（BASIC → ADVANCED → ENTERPRISE）
3. 确认后系统：
   - 更新租户版本字段
   - 记录版本变更日志（含变更类型：INIT/UPGRADE/DOWNGRADE）
   - 刷新功能开关缓存
4. 租户用户下次登录即生效新版本功能

**版本变更日志：**

| 字段 | 说明 |
|------|------|
| 变更前版本 | 原版本 |
| 变更后版本 | 新版本 |
| 变更类型 | INIT（初始化）/UPGRADE（升级）/DOWNGRADE（降级） |
| 操作人 | 执行操作的管理员 |
| 时间 | 变更时间 |

#### 2.4.4 用量统计

平台管理员可查看每个租户的用量信息：
- 当前用户数 / 最大用户数
- 版本变更次数
- 配置项数量
- 当前版本与状态

### 2.5 租户数据隔离范围

以下业务数据均按租户隔离，各租户互不可见：

| 数据类型 | 隔离表 |
|---------|--------|
| 预算编制 | budget_preparation / budget_preparation_detail |
| 报销单 | fee_expense_bill |
| 预算科目 | budget_subject |
| 预算调整 | fee_budget_adjustment_app |
| 资金池 | fee_reserved_budget |
| 映射规则 | fee_mapping_rule |
| 用途标签 | fee_purpose_tag |
| 成本中心 | fee_cost_center |
| 操作日志 | fee_operation_log |
| 福利政策 | fee_welfare_config |
| 工作流配置 | fee_workflow_config / fee_workflow_node_config |

### 2.6 租户级功能配置

平台管理员可为每个租户单独配置功能参数：

| 配置键 | 说明 | 示例值 |
|--------|------|--------|
| approval_flow | 审批流程配置 | JSON |
| welfare_policy | 福利政策配置 | JSON |
| subject_system | 科目体系配置 | JSON |

**操作路径：** 租户详情 → 功能配置

### 2.7 福利政策配置（租户级）

高级版支持按租户配置公司福利政策，用于报销时自动计算补助金额：

| 字段 | 说明 |
|------|------|
| 福利编码 | 租户内唯一 |
| 福利名称 | 如：工作日餐补 |
| 福利大类 | MEAL/TRAVEL/TRANSPORT/OTHER |
| 福利子类 | WORKDAY_MEAL/OVERTIME_MEAL/SHORT_TRIP等 |
| 适用区域 | DOMESTIC/INTERNATIONAL/ALL |
| 城市等级 | TIER1/TIER2/TIER3/ANY |
| 补助标准金额 | 如：50元/天 |
| 计量单位 | DAY/MONTH/TIME/MEAL |
| 最大享受天数 | 0=不限 |
| 适用职级 | ALL/指定职级 |
| 状态 | ENABLED/DISABLED |

### 2.8 高级版租户注意事项

- 高级版租户最大用户数默认为 **50人**
- 试用授权到期后状态自动变为 EXPIRED，需联系平台管理员续期
- 高级版不支持的功能（如报表分析、跨部门分摊等）在界面上自动隐藏
- 如需更多功能，联系平台管理员升级至企业版即可，数据零迁移
- 福利政策配置按租户独立维护，不同企业可设置不同补助标准

## 3. 系统初始化

### 3.1 初始化概述

高级版支持**三条工作流配置**和**部门级资金池**。初始化是上线前的关键步骤，决定了审批流转方式。

### 3.2 工作流配置

高级版支持配置以下三条工作流，每条可设置1~N级审批：

**配置路径：** 费用管理 → 系统初始化 → 工作流配置

#### 2.2.1 预算编制审批工作流

**推荐配置（两级审批）：**

| 审批级别 | 审批角色 | 说明 |
|---------|---------|------|
| 第1级 | 部门经理（deptManager） | 审核本部门预算编制的合理性 |
| 第2级 | 财务总监 | 复核全公司预算平衡 |

**操作步骤：**
1. 进入「工作流配置」页面
2. 选择「预算编制审批」工作流
3. 设置审批级数（如：2）
4. 依次配置每级审批角色
5. 保存配置

#### 2.2.2 报销审核工作流

**推荐配置：**

| 审批级别 | 审批角色 | 说明 |
|---------|---------|------|
| 第1级 | 部门经理 | 审核报销单真实性与合规性 |
| 第2级 | 财务专员 | 复核金额与科目归属 |

#### 2.2.3 预算调整审批工作流

**推荐配置：**

| 审批级别 | 审批角色 | 说明 |
|---------|---------|------|
| 第1级 | 部门经理 | 审批调整申请，扣减部门资金池差额 |
| 第2级 | 财务总监 | 复核调整合理性 |

### 3.3 部门资金池配置

高级版支持**部门级单层资金池**：

| 资金池层级 | 默认初始额度 | 用途 |
|-----------|-------------|------|
| 部门资金池（DEPT） | 10万元 | 预算调整审批时扣减差额 |

**配置步骤：**
1. 进入「费用管理 → 资金池管理」
2. 点击「新增资金池」
3. 层级类型固定为「部门」
4. 设置初始额度（默认10万元）
5. 关联对应部门
6. 保存

> **说明：** 若系统中无部门资金池记录，审批时会自动按默认额度（10万元）创建。

### 3.4 预算科目配置

**配置路径：** 费用管理 → 预算科目

**操作步骤：**
1. 进入「预算科目」页面
2. 点击「新增科目」
3. 填写科目编码、科目名称
4. 选择所属会计大类（费用类/资产类/成本类）
5. 设置科目类型（预算科目/核算科目）
6. 保存

### 3.5 映射规则配置

映射规则是高级版的核心配置，决定报销时如何自动匹配预算科目。

**配置路径：** 费用管理 → 映射规则

**规则字段说明：**

| 字段 | 说明 |
|------|------|
| 物资小类编码 | 报销费用的分类（如：办公用品、差旅交通） |
| 用途标签编码 | 费用用途（如：日常办公、项目交付） |
| 目标预算科目 | 匹配后归入的预算科目 |
| 归属会计大类 | 费用确认的会计分类 |
| 费用确认方式 | DIRECT/DEPRECIATION/ACCRUAL |
| 是否固定资产 | 标记是否需要填写使用年限 |
| 优先级 | 数值越大优先级越高 |

**高级版支持三种费用确认方式：**

| 确认方式 | 编码 | 说明 | 适用场景 |
|---------|------|------|---------|
| 直接费用化 | DIRECT | 一次性计入当期费用 | 日常办公费、差旅费 |
| 折旧 | DEPRECIATION | 按使用年限按月折旧 | 固定资产（设备、车辆） |
| 计提摊销 | ACCRUAL | 按摊销期数按月分摊 | 长期待摊费用（装修） |

> **注意：** 费率利息（FEE_RATE）为企业版专属，高级版中若映射规则配置了FEE_RATE，系统自动降级为DIRECT处理。

**配置示例：**

| 物资小类 | 用途标签 | 目标科目 | 会计大类 | 确认方式 |
|---------|---------|---------|---------|---------|
| 打印纸 | 日常办公 | 办公费 | 费用类 | DIRECT |
| 机票 | 项目交付 | 差旅费 | 费用类 | DIRECT |
| 电脑设备 | 日常办公 | 办公设备 | 资产类 | DEPRECIATION |
| 装修工程 | 办公场所 | 长期待摊 | 资产类 | ACCRUAL |

### 3.6 用途标签配置

**配置路径：** 费用管理 → 用途标签

用途标签用于标记报销费用的具体用途，与物资小类组合后触发映射规则。

**操作步骤：**
1. 进入「用途标签」页面
2. 点击「新增」
3. 填写标签编码（如：DAILY_OFFICE）
4. 填写标签名称（如：日常办公）
5. 保存

**推荐标签：**

| 编码 | 名称 |
|------|------|
| DAILY_OFFICE | 日常办公 |
| PROJECT | 项目交付 |
| TRAVEL | 出差 travel |
| ENTERTAIN | 商务招待 |

### 3.7 成本中心配置

**配置路径：** 费用管理 → 成本中心

| 字段 | 说明 |
|------|------|
| 中心编码 | 唯一标识 |
| 中心名称 | 成本中心名称 |
| 默认会计大类 | EXPENSE/ASSET/COST |
| 状态 | 启用/停用 |

> **说明：** 高级版成本中心用于费用归集管理，不支持跨部门分摊（企业版功能）。

### 3.8 初始化清单

| 序号 | 配置项 | 操作路径 | 必要性 |
|------|--------|---------|--------|
| 1 | 配置预算科目 | 预算科目管理 | 必须 |
| 2 | 配置映射规则 | 映射规则管理 | 必须 |
| 3 | 配置用途标签 | 用途标签管理 | 必须 |

## 4. 预算编制

### 4.1 编制流程概述

高级版预算编制采用向导式三步流程：

```
第一步：基础信息 → 第二步：科目预算编制 → 第三步：预览提交
```

**流程规则：**
- 新增编制：从第一步开始
- 修改编制（被驳回后）：从第二步开始，不可返回第一步
- 查看模式：直接进入第三步

### 4.2 场景一：月度预算编制（含智能填充）

#### 第一步：填写基础信息

1. 进入「费用管理 → 预算编制」
2. 点击「新增编制」
3. 填写基础信息：
   - 编制年度
   - 编制月份
   - 所属部门（自动填充）
   - 编制说明

#### 第二步：科目预算编制

1. 系统自动加载所有启用的预算科目
2. **数据初始化**（高级版智能填充）：
   - 系统自动查询本部门上月已审批通过的报销单数据
   - 按预算科目分组汇总，填充至对应科目的初始化金额
   - 若某科目上月无报销数据，自动回退至上月预算金额
   - 页面提示："已加载上月报销实际数据（N个科目），请根据本月计划调整"
   - 数据源标记为 MIXED（混合数据源）
3. 逐科目调整本月预算金额
4. 对于资产类科目，必须填写使用年限（折旧年限）
5. 点击「下一步」保存

> **跨年处理：** 若当前为1月，系统自动计算上年12月作为"上月"进行数据加载。

#### 第三步：预览与提交

1. 预览所有科目预算汇总表
2. 确认无误后点击「完成编制」
3. 预算单状态变为 `Completed`
4. 点击「提交审核」，进入审批流程

### 4.3 场景二：被驳回后修改重新提交

**驳回规则：**
- 任何一级审批驳回，均回退至编制人员
- 驳回时必须填写驳回原因
- 驳回后预算单状态变为 `Rejected`

**重新提交流程：**
1. 编制人员收到驳回通知
2. 进入预算编制列表，找到被驳回的预算单
3. 点击「修改」，系统从第二步进入
4. 根据驳回原因调整预算金额
5. 点击「完成编制」→「提交审核」
6. **关键规则：** 重新提交后从被驳回的审批级别继续

**示例（两级审批）：**
- 被第1级（部门经理）驳回 → 重新提交后从部门经理审批开始
- 被第2级（财务总监）驳回 → 重新提交后直接从财务总监审批开始，无需再过部门经理

### 4.4 场景三：审批流程（审批人视角）

#### 第1级审批（部门经理）

1. 部门经理登录系统
2. 进入「费用管理 → 预算审核」
3. 查看待审批预算单列表
4. 操作选择：
   - **通过：** 流转至下一级审批
   - **驳回：** 必须填写驳回原因
   - **批量通过：** 支持勾选多条一键通过

#### 第2级审批（财务总监/自定义角色）

1. 审批人登录系统
2. 进入「预算审核」
3. 审核预算汇总
4. **通过后：** 预算状态锁定，不可再修改

### 4.5 预算编制状态流转

```
Draft（草稿）→ Completed（完成编制）→ Pending_Dept_Review（第1级审核中）
→ Pending_Level2_Review（第2级审核中）→ ... → Approved（已通过）

任何审核中状态 → Rejected（已驳回）→ 修改后重新提交
```

> **说明：** 状态中的审核级数取决于工作流配置的审批级数。

## 5. 费用管控（报销管理）

### 5.1 报销流程概述

高级版报销单采用**一步式提交**：
- 创建即提交，无草稿状态
- 无删除功能
- 支持映射规则自动匹配科目
- 支持AI对话式填报
- 支持多币种
- 状态机：`SUBMITTED`（正常提交）或 `OVER_BUDGET_PENDING`（超预算待审）

### 5.2 场景一：AI对话式填报（推荐）

高级版提供AI对话流引导填报，共9步：

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 选择消费大类 | 如：办公用品、差旅交通、固定资产 |
| 2 | 选择物资小类 | 如：打印纸、机票、电脑设备 |
| 3 | 选择用途标签 | 如：日常办公、项目交付 |
| 4 | 选择币种 | CNY/USD/EUR等（多币种支持） |
| 5 | 输入金额 | 提示动态带币种符号 |
| 6 | 费用确认方式确认 | 系统根据映射规则自动判断 |
| 7 | 补充信息 | 根据确认方式动态分支（见下表） |
| 8 | 选择报销年月 | — |
| 9 | 确认提交 | 预览后一步提交 |

**费用确认方式动态分支：**

| 确认方式 | 额外步骤 |
|---------|---------|
| DIRECT（直接费用化） | 无额外步骤 |
| DEPRECIATION（折旧） | 输入折旧年限（年） |
| ACCRUAL（计提摊销） | 输入摊销期数（月） |

> **注意：** 高级版不支持FEE_RATE（费率利息），若映射规则中配置了FEE_RATE，系统自动降级为DIRECT。

### 5.3 场景二：手动表单填报

1. 进入「费用管理 → 费用报销」
2. 点击「新增报销单」
3. 填写表单：
   - 物资小类（下拉选择）
   - 用途标签（下拉选择）
   - 项目编号（非必填）
   - 报销金额
   - 币种（默认CNY）
   - 费用发生日期（默认当天）
4. 系统自动执行映射规则匹配：
   - 根据「物资小类 + 用途标签」查询映射规则
   - 自动填充预算科目和会计大类
   - 展示预算归属预览（含科目名称与可用余额）
5. 若为固定资产，填写使用年限（必填）
6. 点击「提交」

### 5.4 场景三：超预算报销

当报销金额超过对应预算科目可用余额时：

1. 系统自动检测超预算
2. 报销单状态变为 `OVER_BUDGET_PENDING`（超预算待审）
3. 系统自动创建超预算审批单
4. 进入超预算审批流程：
   - 审批人可查看该科目当前预算金额、已用金额、本次报销金额
   - 审批人可选择：
     - **通过：** 报销单生效，扣减预算余额
     - **驳回：** 报销单作废
     - **调整科目预算：** 直接调增该科目预算额度后通过

### 5.5 场景四：多币种报销

高级版支持多币种报销：

1. 在AI对话流第4步或手动表单中选择币种
2. 系统自动获取汇率进行换算
3. 报销单记录原币金额（originalAmount）和人民币金额（amount）
4. 预算扣减以人民币金额为准

### 5.6 场景五：固定资产报销（折旧）

1. 发起报销，选择物资小类「电脑设备」+ 用途标签「日常办公」
2. 映射规则匹配：费用确认方式 = DEPRECIATION，固定资产 = 是
3. AI对话流提示输入「折旧年限」
4. 输入使用年限（如：5年）
5. 系统按月自动计算折旧额 = 金额 / (使用年限 × 12)
6. 报销单提交，进入审批

### 5.7 场景六：长期待摊费用报销（摊销）

1. 发起报销，选择物资小类「装修工程」+ 用途标签「办公场所」
2. 映射规则匹配：费用确认方式 = ACCRUAL
3. AI对话流提示输入「摊销期数（月）」
4. 输入摊销期数（如：36月）
5. 系统按月自动计算摊销额 = 金额 / 摊销期数
6. 报销单提交，进入审批

### 5.8 报销审批（审批人视角）

1. 审批人进入「费用管理 → 报销审批」
2. 查看待审批报销单列表
3. 点击报销单查看详情：
   - 报销人、部门
   - 物资小类、用途标签
   - 金额、币种
   - 归属预算科目及可用余额
   - 支出类型标签（收益性支出/折旧类/摊销类）
4. 审批操作：
   - **通过**
   - **驳回**
   - **批量通过**（勾选多条）

## 6. 预算调整

### 6.1 调整流程概述

高级版预算调整采用**可配置多级审批 + 部门资金池差额扣减**机制。

### 6.2 场景一：编制人员发起预算调整申请

**操作步骤：**
1. 进入「费用管理 → 预算调整」
2. 点击「新增申请」
3. 填写申请信息：
   - 选择物资小类（与报销单一致）
   - 选择用途标签
   - 系统自动匹配目标预算科目（通过映射规则）
   - 展示预算归属预览（科目名称 + 当前可用余额）
   - 输入申请金额（调整后的目标金额）
   - 填写调整原因
4. 提交申请

**申请提交后：**
- 申请单状态变为「部门审批中」
- 编制人员可在列表查看自己提交的申请（按申请人过滤）
- 审批中状态可执行「取消」操作

### 6.3 场景二：部门经理审批（第1级）

**审批页面信息：**
- 申请单号、申请人、目标科目
- 申请金额（目标金额）
- 预算可用余额（当前余额）
- 部门名称
- 资金池信息（部门资金池总额/已分摊/可用）

**差额分摊逻辑：**
```
差额（allocateAmount）= 申请金额 - 预算可用余额
```

**审批操作：**
- **通过：**
  - 系统从部门资金池扣减差额
  - 目标科目余额更新为申请金额
  - 申请单流转至下一级审批
- **驳回：**
  - 必须填写驳回原因
  - 预算余额和资金池不变
  - 编制人员可修改后重新提交

**资金池不足处理：**
- 若部门资金池可用余额不足以覆盖差额
- 系统提示预警信息
- 审批人可选择驳回

### 6.4 场景三：上级审批（第2~N级）

根据工作流配置，可能有更多审批级别：
- 各级审批人查看申请详情
- 通过/驳回操作
- 通过后流转至下一级

### 6.5 场景四：终审通过后预算生效

最终审批通过后：
1. 系统自动将 `budget_preparation_detail.budget_amount` 更新为申请金额
2. 所有后续的可用余额计算均基于更新后的数据
3. 不再关联或查询调整表

### 6.6 资金池自动创建机制

若审批时部门无资金池记录：
- 系统自动创建默认资金池（部门：10万元）
- 将创建的 reservedId 回写至申请单

### 6.7 预算调整状态流转

```
部门审批中(DEPT_APPROVING) → 第2级审批中 → ... → 已通过(APPROVED)

任何审批中 → 已驳回(REJECTED) → 可修改重提
任何审批中 → 已撤回(CANCELLED)（申请人主动取消）
```

## 7. 常见场景操作指南

### 7.1 场景：中型企业上线初始化

**完整初始化清单：**

| 序号 | 配置项 | 操作路径 | 耗时估计 |
|------|--------|---------|---------|
| 1 | 配置预算科目（10~20个） | 预算科目管理 | 20分钟 |
| 2 | 配置用途标签 | 用途标签管理 | 10分钟 |
| 3 | 配置映射规则 | 映射规则管理 | 30分钟 |
| 4 | 配置工作流（3条） | 系统初始化 | 15分钟 |
| 5 | 配置部门资金池 | 资金池管理 | 10分钟 |
| 6 | 配置成本中心 | 成本中心管理 | 10分钟 |
| 7 | 分配角色权限 | 系统管理 → 角色 | 15分钟 |

### 7.2 场景：月度预算编制闭环

```
月初 → 编制人员新建预算（自动加载上月实绩）
     → 调整各科目标金额
     → 完成编制 → 提交审核
     → 部门经理审批 → 财务总监审批
     → 预算生效
日常 → 员工通过AI对话填报报销单
     → 映射规则自动匹配科目
     → 审批通过 → 扣减余额
月末 → 查看各科目执行情况
```

### 7.3 场景：固定资产采购报销

1. 员工进入AI对话填报
2. 选择消费大类「固定资产」→ 物资小类「电脑设备」→ 用途标签「日常办公」
3. 选择币种 CNY
4. 输入金额 12,000 元
5. 系统识别确认方式 = DEPRECIATION
6. 提示输入折旧年限 → 输入 5 年
7. 系统展示：月折旧额 = 12000 / 60 = 200 元/月
8. 确认提交
9. 进入审批流程

### 7.4 场景：办公室装修费摊销

1. 员工进入AI对话填报
2. 选择物资小类「装修工程」→ 用途标签「办公场所」
3. 输入金额 360,000 元
4. 系统识别确认方式 = ACCRUAL
5. 提示输入摊销期数 → 输入 36 月
6. 系统展示：月摊销额 = 360000 / 36 = 10,000 元/月
7. 确认提交

### 7.5 场景：外币报销

1. 员工出差归来，有美元发票
2. AI对话填报，选择币种「USD」
3. 输入原币金额 500 USD
4. 系统自动获取当日汇率（如 7.2）
5. 自动计算人民币金额 = 500 × 7.2 = 3,600 元
6. 预算扣减以 3,600 元为准
7. 提交审批

### 7.6 场景：预算不足需要调整

**完整流程：**
1. 编制人员发现某科目预算不足
2. 进入「预算调整」→「新增申请」
3. 选择物资小类 + 用途标签 → 系统自动定位目标科目
4. 查看当前可用余额，输入目标金额
5. 提交 → 部门经理审批（扣减资金池差额）
6. → 财务总监审批
7. → 审批通过 → 科目余额自动更新为目标金额
8. 后续报销即可使用新额度

### 7.7 场景：超预算紧急报销

1. 员工提交报销单，金额超出科目余额
2. 系统自动标记为超预算，状态变为 OVER_BUDGET_PENDING
3. 审批人进入「超预算审批」
4. 查看：科目预算额、已用额、本次报销额
5. 审批人判断：
   - 合理 → 通过
   - 需调增科目额度 → 调整科目预算后通过
   - 不合理 → 驳回
6. 若需长期增加额度 → 走预算调整流程

| 方式 | 编码 | 版本要求 | 额外输入 |
|------|------|---------|---------|

### E. 高级版功能边界（不支持清单）

以下功能在高级版中不可用，升级至企业版后可解锁：

| 功能 | 说明 |
|------|------|
| 三级资金池 | 仅支持部门级，无分公司/总公司层级 |
| 跨部门费用分摊 | 不支持按人数/面积/收入分摊 |
| 盈利分析报表 | 无明细视图/汇总视图 |
| 异常监控报表 | 无预算归属异常监控 |

| AI私有化部署 | 仅支持标准AI对话 |
| AI智能审批摘要 | 不支持 |
| 完整三级审批 | 无固定部门→分公司→总公司流程 |

### F. 版本升级路径

```
基础版 → 高级版 → 企业专业版
```

升级方式：替换版本配置 → 执行增量SQL → 重启服务，数据零迁移。
