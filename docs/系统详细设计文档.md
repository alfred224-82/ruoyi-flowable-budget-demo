### 1.4 多租户架构设计

```
┌─────────────────────────────────────────────────────────┐
│  请求入口 (Sa-Token 认证)                                │
│  → 从 LoginUser 中获取 tenantId                         │
│  → 存入 TenantContextHolder (ThreadLocal)               │
└─────────────────────┬───────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────┐
│  MyBatis-Plus TenantLineInnerInterceptor               │
│  → SELECT/UPDATE/DELETE 自动追加 WHERE tenant_id = ?    │
│  → INSERT 自动填充 tenant_id 字段                      │
│  → 平台管理员请求忽略租户过滤（@InterceptorIgnore）  │
└─────────────────────┬───────────────────────────────────┘
                      ▼
┌─────────────────────────────────────────────────────────┐
│  版本控制叠加：                                         │
│  sys_tenant.edition → 租户级功能开关                   │
│  + sys_license.features → 全局功能开关                 │
│  = 实际可用功能集（取交集）                           │
└─────────────────────────────────────────────────────────┘
```

**核心设计原则**：
- 所有业务表均包含 `tenant_id BIGINT NOT NULL` 字段
- 平台管理员（platform_admin）通过 `@InterceptorIgnore(tenantLine = "true")` 跳过租户过滤
- 租户版本分配后，功能开关立即生效（内存缓存 + Redis 发布订阅通知刷新）
- 创建租户时自动初始化租户管理员账号 + 默认角色 + 默认菜单

### Task 1.3：License 服务实现（核心逻辑）

**文件**：`ruoyi-system/src/main/java/com/ruoyi/system/service/impl/LicenseServiceImpl.java`

```java
@Service
@RequiredArgsConstructor
public class LicenseServiceImpl implements ILicenseService {
    private final SysLicenseMapper licenseMapper;
    private volatile SysLicense cachedLicense;
    private volatile Set<String> enabledFeatures;

    @Override
    public boolean validateLicense() {
        SysLicense license = licenseMapper.selectLatest();
        if (license == null) { degradeToBasic(); return false; }
        // 1. RSA-SHA256 验签
        if (!verifySignature(license)) { degradeToBasic(); return false; }
        // 2. 机器指纹校验
        if (!getMachineFingerprint().equals(license.getMachineFingerprint())) { degradeToBasic(); return false; }
        // 3. 防时钟回拨
        if (license.getLastCheckTime() != null && new Date().before(license.getLastCheckTime())) { degradeToBasic(); return false; }
        // 4. 防降级回滚
        if (cachedLicense != null && license.getLicenseVersion() < cachedLicense.getLicenseVersion()) { degradeToBasic(); return false; }
        // 5. 有效期校验
        if (license.getExpireDate() != null && new Date().after(license.getExpireDate())) { degradeToBasic(); return false; }
        // 6. 试用天数校验
        if ("TRIAL".equals(license.getLicenseType())) {
            long usedDays = ChronoUnit.DAYS.between(license.getIssueDate().toInstant(), Instant.now());
            if (usedDays > license.getTrialDays()) { degradeToBasic(); return false; }
        }
        // 校验通过
        license.setLastCheckTime(new Date());
        licenseMapper.updateById(license);
        cachedLicense = license;
        enabledFeatures = parseFeatures(license.getFeatures());
        return true;
    }

    @Override
    public boolean isFeatureEnabled(String featureKey) {
        return enabledFeatures != null && enabledFeatures.contains(featureKey);
    }

    private void degradeToBasic() {
        cachedLicense = new SysLicense();
        cachedLicense.setEdition("BASIC");
        enabledFeatures = Collections.emptySet();
    }
}
```

```java
@Component
@RequiredArgsConstructor
public class FeatureInterceptor implements HandlerInterceptor {
    private final ILicenseService licenseService;
    @Override
    public boolean preHandle(HttpServletRequest request, HttpServletResponse response, Object handler) {
        if (!(handler instanceof HandlerMethod)) return true;
        RequireFeature ann = ((HandlerMethod) handler).getMethodAnnotation(RequireFeature.class);
        if (ann != null && !licenseService.isFeatureEnabled(ann.value())) {
            throw new ServiceException("当前版本不支持此功能，请升级License");
        }
        return true;
    }
}
```

## 十四、Phase 13：企业版增量功能

### Task 13.1：周期计提引擎（FEE_ACCRUAL_ENGINE）

```java
@Override
public List<FeeWelfareConfigVo> matchWelfare(String region, Integer tripDays, String cityLevel, String countryGroup) {
    LambdaQueryWrapper<FeeWelfareConfig> wrapper = Wrappers.lambdaQuery();
    wrapper.eq(FeeWelfareConfig::getStatus, "ENABLED")
           .eq(FeeWelfareConfig::getCategory, "TRAVEL")
           .le(FeeWelfareConfig::getEffectiveDate, new Date())
           .and(w -> w.isNull(FeeWelfareConfig::getExpiryDate)
                      .or().ge(FeeWelfareConfig::getExpiryDate, new Date()));
    // 区域匹配
    wrapper.and(w -> w.eq(FeeWelfareConfig::getRegion, region)
                      .or().eq(FeeWelfareConfig::getRegion, "ALL"));
    // 国内：按城市等级匹配
    if ("DOMESTIC".equals(region)) {
        wrapper.and(w -> w.eq(FeeWelfareConfig::getCityLevel, cityLevel)
                          .or().eq(FeeWelfareConfig::getCityLevel, "ANY"));
    }
    // 国外：按国家分组匹配
    if ("INTERNATIONAL".equals(region)) {
        wrapper.and(w -> w.eq(FeeWelfareConfig::getCountryGroup, countryGroup)
                          .or().eq(FeeWelfareConfig::getCountryGroup, "ANY"));
    }
    List<FeeWelfareConfig> configs = baseMapper.selectList(wrapper);
    // 短期/长期自动切换：超过30天返回长期标准
    return configs.stream()
        .filter(c -> matchDuration(c, tripDays))
        .map(this::toVo)
        .collect(Collectors.toList());
}

private boolean matchDuration(FeeWelfareConfig config, Integer tripDays) {
    if ("ANY".equals(config.getTripDuration())) return true;
    if ("SHORT".equals(config.getTripDuration())) return tripDays <= 30;
    if ("LONG".equals(config.getTripDuration())) return tripDays > 30;
    return false;
}
```

```java
    // 计算补助总额 = 短期天数×短期标准 + 长期天数×长期标准
    BigDecimal subsidyTotal = calculateSubsidy(standards, trip.getTripDays());
    bill.setSubsidyAmount(subsidyTotal);
    // 福利金额归集至职工福利费科目
    bill.setSubjectCode("6602.03"); // 职工福利费
}
```
