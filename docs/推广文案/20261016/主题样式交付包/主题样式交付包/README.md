# 小账本 H5 · 四主题样式交付包

## 文件说明
| 文件 | 作用 | 体积(gzip) |
|---|---|---|
| theme_tokens.css | 四主题设计变量（配色/圆角/阴影/字号/动效） | 2.1 KB |
| components.css | 19 个页面通用组件，组件只写一份 | 3.8 KB |
| icons.svg | 图标 + 空状态插画 + 手绘装饰（SVG sprite） | 2.0 KB |
| theme_demo.html | 四主题切换演示页，浏览器直接打开 | — |

**合计 gzip 后 7.9 KB**，替代原 76 张图片方案（5.2 MB）。

## 如何使用
1. HTML 根节点设置主题：`<html data-theme="t1">`
   - t1 清新简约 / t2 活力渐变（偏红）/ t3 暗黑科技 / t4 温暖手绘
2. 切主题只改这一个属性，无需重新加载任何资源
3. 图标用法：`<svg class="ico"><use href="#i-home"/></svg>`

## 主题差异一览
| 项 | t1 | t2 | t3 | t4 |
|---|---|---|---|---|
| 背景 | #F6F8FC | #FFF1F0 | #0B0F19 | #FFF9F0 |
| 主色 | #4F8FF7 | #F5455C→#FF7A45 | #5B8FFF | #FFB347 |
| 强调/辅助 | #7AB8FF | #FFD166 | #00E5FF | #FF8A8A |
| 卡片圆角 | 12px | 16px | 10px | 18px |
| 按钮圆角 | 24px | 28px | 24px | 22px |
| 行距 | 1.6 | 1.6 | 1.6 | 1.7 |
| 图标风格 | 线性 | 圆润面状 | 面状发光 | 手绘涂鸦 |

字号四主题统一：主标题 28px 加粗 / 副标题 18px / 正文 15px / 左右留白 16px。

## 已内置的主题专属动效
- t2：主按钮呼吸光（box-shadow 循环）
- t3：卡片 1px 描边、数字与选中态用青色
- t4：标题摇摆入场、标签贴纸感（圆角 14px + 轻微旋转）、进度条胶囊化
- 全部：`prefers-reduced-motion` 下自动关闭动效

## 注意事项
1. icons.svg 需与页面同源，或用 `<img>` 外链（跨域时 use 不生效）
2. 生产环境建议把 SVG sprite 内联进 HTML，省一次请求
3. 二维码区域在 t3 下自动加深色底框，保证扫码识别率
4. 真正需要图片的只有：活动宣传图、用户头像、二维码位图——这三类仍需服务端生成缩略图
