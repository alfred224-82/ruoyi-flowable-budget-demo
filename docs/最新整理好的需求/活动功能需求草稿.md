# 系统功能需求草稿

> 涉及模块：系统模板 - 行业模板、租户管理员、老板端 - 活动设置
> 版本：草稿 v0.1　状态：待确认 / 待补充细节

## 一、需求概述

本需求围绕活动相关功能展开，涉及三个层级的配置与交互：

1. **系统管理员**：在「行业模板」中按行业开启是否支持语音的开关；
2. **租户管理员**：在自身配置中勾选 / 取消语音功能（受系统管理员开关约束）；
3. **老板端（活动设置）**：创建活动时提供项目、房间、员工的选择，以及自动生成标题、背景图上传、推荐二维码等功能。

## 二、功能一：行业「是否可语音」开关

### 2.1 功能说明

在系统模板的「行业模板」配置中，为行业增加一项「是否可语音」的功能开关，用于控制该行业下的租户是否具备语音能力。

### 2.2 三级控制逻辑

| 层级 | 配置位置 | 说明 |
| --- | --- | --- |
| 系统管理员 | 系统模板 → 行业模板 | 为该行业开启或关闭「是否可语音」能力，这是总开关 |
| 租户管理员 | 租户管理员配置页 | 系统管理员已开启时，租户可勾选或取消勾选；未开启则不显示 / 不可勾选 |
| 老板端 | 活动设置 | 取决于租户管理员的勾选结果，决定活动中是否启用语音相关能力 |

### 2.3 控制规则（状态矩阵）

| 系统管理员设置 | 租户管理员处表现 | 老板端表现 |
| --- | --- | --- |
| 未开启（关闭） | 不显示该选项 / 不可勾选（隐藏） | 无语音能力 |
| 已开启（开放） | 显示该选项，租户可勾选或取消勾选 | 依据租户勾选结果生效 |

核心原则：**系统管理员决定「能不能」，租户管理员决定「用不用」**。系统级未开放时，租户无权自行开启。

### 2.4 语音功能在老板端的具体表现

- 当租户已勾选语音功能时，老板端创建活动时可以上传一段**活动介绍语音**；
- 语音为**单向播放**，不做语音互动，仅作为活动的语音介绍；
- 语音时长约 **3 分钟**；
- 当租户**未勾选**语音功能时，老板端**完全隐藏**语音相关入口（不显示上传语音的按钮 / 区域），而非置灰。

## 三、功能二：老板端 - 活动设置

### 3.1 选择项目（单选）

活动设置页提供一个「项目」下拉框，规则如下：

- 只能选择一个项目；
- 作为活动的主体定位，例如「狼人杀」「剧本杀」等。

### 3.2 选择房间（多选，数量由老板决定）

活动设置页提供一个「房间」下拉框，规则如下：

- 可以选择多个房间；
- 可选数量**不做上限控制**，由老板自行决定勾选几个即几个。

### 3.3 选择员工（多选，数量由老板决定）

活动设置页提供一个「员工」下拉框，规则如下：

- 可以选择多个员工（例如主持人 DM）；
- 可选数量**不做上限控制**，由老板自行决定勾选几个即几个。

### 3.4 可多选的开关配置

房间和员工是否支持多选，需要在「租户管理员」侧进行配置，该配置项对老板端生效：

| 配置项 | 配置位置 | 作用 |
| --- | --- | --- |
| 房间是否可多选 | 租户管理员配置 | 控制老板端「选择房间」下拉框单选 / 多选 |
| 员工是否可多选 | 租户管理员配置 | 控制老板端「选择员工」下拉框单选 / 多选 |

> 注：多选时不设置数量上限，老板勾选几个就是几个。

### 3.5 活动标题自动生成

根据选择的项目、房间、员工，自动拼接生成活动标题。**不支持自定义模板**，使用系统固定拼接规则。

- 项目（必选，单个）+ 房间（一个或多个）+ 员工（一个或多个）；
- 拼接规则：项目名 + 房间名 + 「玩」+ 活动类型，并由「XX 主持」。

标题示例：

> 大房间玩狼人杀，由 DM 某某某主持

当房间 / 员工为多选时，用顿号连接，或只显示首个 +「等 N 个」。

## 3.6 背景图片（仅对当前活动生效）

活动背景图片**仅作用于当前活动**，不跨活动复用：

- 每次创建活动时需上传对应的背景图；
- 背景图的作用范围为**单个活动**，不影响其他活动；
- 如需要更换，提供「更换 / 重新上传」入口。

### 3.7 推荐码 / 微信二维码

老板端生成活动的同时，生成一个推荐码与对应的微信小程序二维码：

- 二维码为**微信小程序码**，用户扫码可直接进入微信小程序；
- 二维码携带 **租户ID（tenantId）+ 用户ID（userId）** 参数，用于确定进入小程序的具体页面；
- 二维码与活动绑定，用于活动推广与扫码引流。

## 四、业务流程（整体串联）

| 步骤 | 操作方 | 动作 |
| --- | --- | --- |
| 1 | 系统管理员 | 在行业模板中为该行业设置「是否可语音」 |
| 2 | 租户管理员 | 在自身配置中勾选 / 取消语音；同时配置房间、员工是否允许多选 |
| 3 | 老板端 | 创建活动，选择项目（单选）、房间（多选）、员工（多选） |
| 4 | 系统自动 | 根据项目 + 房间 + 员工生成活动标题 |
| 5 | 系统自动 | 上传当前活动的背景图（仅对本次活动生效） |
| 6 | 系统自动 | 生成推荐码与微信小程序二维码 |

## 五、已确认问题记录

| 问题 | 结论 |
| --- | --- |
| 「是否可语音」在老板端具体影响什么？ | 影响活动，有语音可以播放一段介绍活动的语音（约 3 分钟），不做互动 |
| 租户未勾选语音时，老板端表现？ | **完全隐藏**语音相关入口 |
| 房间 / 员工多选的数量上限？ | 由老板决定，勾选几个就是几个，**不做上限控制** |
| 标题生成规则是否支持自定义模板？ | **不需要**，使用系统固定拼接规则 |
| 背景图上传一次的作用范围？ | **仅对当前活动**生效，不跨活动复用 |
| 推荐码的跳转逻辑？ | 推荐码为小程序二维码，携带 tenantId + userId 参数确定进入的页面 |
