-- 员工联系方式公开开关（按员工单独设置，默认全关）
CREATE TABLE `staff_contact_public` (
  `id` BIGINT PRIMARY KEY AUTO_INCREMENT,
  `tenant_id` BIGINT NOT NULL,
  `staff_id` BIGINT NOT NULL COMMENT 'FK→sys_user.user_id（员工）',
  `show_phone` TINYINT(1) NOT NULL DEFAULT 0 COMMENT '公开手机号：0=关 1=开',

  UNIQUE KEY `uk_tenant_staff` (`tenant_id`, `staff_id`)

### 6.2 结算单示例（旅游行业，数字可复算）

| 项目 | 预估 | 实际 | 差额 |
|------|-----:|-----:|-----:|
| 票面收入 | 3000（15人） | 2600（13人） | −400 |
| 追加收入 | 0 | 780 | +780 |
| 收入合计 | 3000 | 3380 | +380 |
| 员工成本 | 400 | 400 | 0 |
| 其他成本 | 2000 | 2000 | 0 |
| 成本合计 | 2400 | 2400 | 0 |
| **利润** | **600** | **980** | **+380** |

### 6.3 验收要点

1. **代收隔离**：代收机票 3000 → 不计入收入/利润 → 配代付机票 3000 成本 → 现金流与账面利润一致。
2. **员工成本自动**：员工成本行由快照自动生成 → 删除某员工后即时重算 → 不可手填。
3. **历史不可变**：结算单提交锁定后 → 不可编辑 → 发现错误只能追加调整单。
4. **利润公式**：利润 = 票面收入 + 追加收入 − 员工成本 − 其他成本；代收不计入。

### 8.2 三层利润模型

| 层级 | 名称 | 计算口径 | 回答的问题 |
|:----:|------|---------|-----------|
| 第一层 | 单场毛利 | 单场收入合计 − 单场成本合计 | 这一场赚没赚 |
| 第二层 | 月毛利 | 当月所有已结算活动的单场毛利之和 | 这个月的活动赚没赚 |
| 第三层 | 月净利润 | 月毛利 − 月分摊固定成本 − 税费 | 这个月真正赚到多少 |

### 8.3 验收要点

1. **三层口径**：单场毛利之和 = 月毛利；月毛利 − 固定成本 = 税前利润；税前利润 − 税费 = 月净利润。
2. **成本分类**：员工分成进单场变动成本；员工底薪进月分摊固定成本；两者分开不混。
3. **月保本线**：月保本毛利 = 固定成本合计 = 12200；月保本场次 = ceil(12200/4700) = 3 场。
4. **历史不可变**：月结锁定后 → 不可编辑 → 错误走调整单。
