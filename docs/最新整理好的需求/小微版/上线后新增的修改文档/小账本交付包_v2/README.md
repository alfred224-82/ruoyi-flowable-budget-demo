## 第四章：隐私分级原则（总纲）
**门店信息公开，个人信息默认不公开；需要时由管理端可控释放。**

五原则：默认收紧、可控释放、最小够用、本人优先、集中管理。

信息分级：
| 级别 | 内容 | 默认可见性 | 控制方 |
|---|---|---|---|
| L1 门店信息 | 名称/地址/客服电话微信 | 全部顾客可见 | 默认公开 |
| L2 业务信息 | 活动/座位占用/主持人姓名 | 相关顾客可见 | 系统规则 |
| L3 个人联系方式 | 员工手机/微信 | 默认不可见 | 本人/老板开关 |
| L4 顾客个人信息 | 顾客手机/姓名/头像 | 仅员工老板可见 | 系统规则 |

三处应用：选座页(6.3)、员工名片(8.2)、门店联系方式(8.3/6.8)

两条配套规则：
- **隐藏必须配套补偿** —— 选座页隐藏姓名必须有分享座位表补偿
- **隐私与可用不冲突** —— 员工开关全关，顾客仍有门店联系方式
