## 一、核心决策

### 1.1 敏感词只有一套，不区分来源

> 不管内容是从**打字**、**语音转写**还是**图片 OCR** 来的，过的都是**同一个敏感词引擎、同一套词库**。

```
┌──────────────────────────────────────┐
│        统一敏感词引擎（文本）          │
│   政治 / 色情 / 暴恐 / 广告 / 自定义   │
├──────────────┬──────────┬────────────┤
│ 语音 ASR 转写 │ 文字输入  │ 图片 OCR   │
│   → 匹配 ✅   │ → 匹配 ✅ │ → 匹配 ✅   │
└──────────────┴──────────┴────────────┘

图片视觉审核（色情 / 暴恐 / 政治标志）→ 独立 API，不经过敏感词
```

- **图片的画面违规**（色情/暴恐/政治标志）走**独立的视觉审核 API**，不在敏感词里。
- 因此"图片过敏感词"实际是：**OCR 抽出图里文字 → 送敏感词引擎**。

### 1.2 图片合规 = 两路并行，与语音同逻辑

> **不过就打回让用户换，不做人工复核**（与语音打回流完全一致）。

```
用户上传图片
  → 并行执行：
      ① OCR 提取文字 → 送统一敏感词引擎（与语音/文字共用词库 ✅）
      ② 视觉内容审核 API（色情 / 暴恐 / 政治标志）
  → 任一不通过 → 返回失败，"图片未通过合规检查，请更换后重新上传"
  → 用户可无限次重新上传，直到通过
```

## 二、图片合规检测

### 2.1 适用范围
- 活动封面图、项目展示图
- 顾客评价配图
- 推广海报

### 2.2 上传限制（硬性约束）

| 限制项 | 值 |
|---|---|
| **大小** | ≤ 5MB |
| **格式** | jpg / jpeg / png / bmp / webp |
| **来源** | PC 后台上传（同语音采集端） |

### 2.3 成本估算（参考，以厂商账单为准）
- OCR ≈ 0.005 元/张（腾讯云）
- 图片审核 ≈ 0.002 ~ 0.01 元/张
- **单次图片合规总成本 ≈ 0.01 元以内**

### 2.4 边界声明（非目标）
- **不做**图片编辑、**不做**人脸比对、**不做**水印检测。
- **不承诺** 100% 识别，低置信度统一打回重传（与语音一致）。
- 纯画面违规（无文字的图片）只走视觉 API 一路，敏感词一路对其无效——**这是正常设计，非缺陷**。

## 三、Admin 全局敏感词管理

### 3.1 定位
- **Admin 维护全局敏感词底库**，作为平台级合规底线。
- 敏感词**不区分输入渠道**：语音转写、文字输入、评价、活动描述、图片 OCR 统一过审。

### 3.2 词库结构

| 字段 | 说明 |
|---|---|
| 敏感词 | 关键词文本 |
| 分类 | 政治 / 色情 / 暴恐 / 广告 / 自定义 |
| 匹配模式 | 精确匹配 / 模糊匹配 / 正则 |
| 生效行业 | 全部 / 指定行业（如足浴行业额外加词） |
| 状态 | 启用 / 禁用 |

### 3.3 继承关系
- **全局底库**（Admin 维护，**唯一**）：平台级合规底线。
- **租户自定义词**（租户管理员追加）：仅本租户生效，与全局底库**合并检测**。
- **老板端**：只读查看命中记录，**不可改词库**。

### 3.4 返回结果
- 命中 → 返回 `FAIL`，附命中词 + 分类 + 位置。
- 未命中 → 返回 `PASS`。
- 调用方（语音/文字/图片模块）自行决定「打回重传」或「标记待审」。

### 3.5 Admin「平台合规」菜单（新增/调整项）

- 语音合规总开关
- **图片合规开关** 🔥
- 录音留存策略（全局上限）
- **敏感词管理**（全局词库，文本/语音/OCR 通用）🔥
- **图片违规类型配置**（色情/暴恐/政治标志，勾选启用）🔥
- 合规告警看板

## 附录 A：合规敏感词分类示例库（供初始化与扩充参考）

> **说明**
> 1. 本附录为**示例词库**，用于 Admin 首次初始化全局敏感词库时导入，以及租户自定义扩充时参考。
> 2. 依据《中华人民共和国广告法》第九条、《网络信息内容生态治理规定》第六条/第七条，以及各内容平台违禁词清单整理 [citation:1][citation:2][citation:3]。
> 3. **官方未公布完整敏感词列表**，实际词库需在运营中持续动态扩充；下表为**分类结构与典型示例**，不代表穷尽。
> 4. 支持**精确匹配 / 模糊匹配 / 正则**三种模式，方言、谐音、拼音、变体由"自定义"分类补充。
> 5. **图片中的敏感词**：经 OCR 提取文字后，走同一套匹配（见 1.1）。

### A.1 分类总览

| 分类 | 来源依据 | 典型场景 | 匹配方式建议 |
|---|---|---|---|
| **政治/涉密** | 《治理规定》第六条 | 旅游讲解、宣传文案 | 精确 + 正则 |
| **色情/低俗** | 《广告法》《治理规定》 | 语音/OCR/评价 | 精确 + 模糊 |
| **暴恐/违禁** | 《治理规定》第六条 | 活动描述、图片 | 精确 |
| **广告极限词** | 《广告法》第九条 | 旅游项目介绍、海报 | 精确 + 正则 |
| **迷信/封建** | 《治理规定》第六条 | 疗愈/研学项目宣传 | 精确 |
| **谩骂/歧视** | 《治理规定》第七条 | 评价、留言 | 模糊 |
| **谣言/虚假** | 《治理规定》第六条 | 旅游宣传、公告 | 人工 + 正则 |
| **自定义（行业/方言）** | 租户自行维护 | 本地项目名、方言变体 | 任意 |

### A.2 政治 / 涉密类（平台红线，禁用）

> 对应《治理规定》第六条（一）~（四）、（七）[citation:2][citation:18][citation:22]

- **国家象征亵渎**：国旗、国徽、国歌、军旗、军徽、党旗（含变相使用、P 图恶搞）
- **国家机关/人员名义**：国家机关、国家机关工作人员、国家领导人（借名宣传、变相使用形象）
- **主权/统一**：台独、藏独、疆独、港独、分裂国家、破坏统一
- **敏感组织/人物**：邪教、非法组织、反动组织名称；特定敏感人物姓名（含影射、暗喻、谐音）
- **宗教/迷信煽动**：破坏宗教政策、宣扬邪教

### A.3 广告极限词 / 虚假宣传类（罚款高风险，《广告法》第九条）

> 使用"国家级、最高级、最佳"等属违法，《广告法》第九条明确禁止 [citation:1][citation:13][citation:17]

**① "最/极" 系列**
- 最、最佳、最优、最好、最大、最高、最高级、最高档、最低、最低价、最便宜、最流行、最受欢迎、最先进、最时尚、极致、极端、极品、绝佳、绝对

**② "一/首/国" 系列**
- 第一、中国第一、全网第一、销量第一、排名第一、唯一、第一品牌、NO.1、TOP.1、独一无二
- 首个、首选、首发、全国首家、全国首发、首席、首屈一指
- 国家级、世界级、全球级、国际级、国家级产品、填补国内空白、国际品质、国门、国宅

**③ 极限/稀缺/权威**
- 顶级、顶尖、尖端、终极、至尊、至臻、巅峰、空前、绝后、绝版、绝无仅有、史无前例、无与伦比、无可比拟、万能、永久
- 独家、独创、首创、发明者、缔造者、创始者
- 金牌、名牌、王牌、大牌、领袖品牌、世界领先、遥遥领先、领导者、巨星、掌门人、之王、冠军、驰名商标、老字号
- 特供、专供、专家推荐、国家免检、免抽检（无法考证或违法宣称）

**④ 虚假承诺 / 诱导**
- 100%、零风险、无效退款、包过、一次通过
- 秒杀、抢疯了、万人疯抢、再不抢就没了、史上最低价、最后一天、仅此一次
- 点击领奖、恭喜获奖、全民免单、免费领取、领取奖品（疑似欺骗点击）

### A.4 色情 / 低俗类

> 《广告法》第九条"含有淫秽、色情……内容"；《治理规定》第七条"性暗示、性挑逗" [citation:1][citation:22]

- **露骨/交易**：淫秽、色情、性行为、卖淫、招嫖、色情交易、性器官直称
- **低俗/擦边**：性暗示、性挑逗、聊骚、低俗、媚俗、庸俗、擦边球、约炮、嫖娼
- **辱骂性低俗词**：装逼、草泥马、傻逼、妈的、JB、屌、绿茶婊、碧池、日了狗 等（含谐音、拼音变体）
- **涉未成年人不良内容**：诱导未成年人不良嗜好、不安全行为

### A.5 暴恐 / 违禁 / 违法犯罪类

> 《治理规定》第六条（五）（九）[citation:2][citation:22]

- **暴恐/极端**：恐怖主义、极端主义、暴恐组织名称、煽动恐怖活动、暴力血腥、凶杀
- **武器**：枪支弹药、炸弹、管制刀具（含展示/教学）
- **毒品**：吸毒、制毒、贩毒、毒品名称
- **赌博**：赌博、赌球、赌马、老虎机、彩票预测、外围
- **违法活动**：传销、资金盘、拉人头、层级返利、刷单、套现、假证、代考、走私
- **侵权/隐私**：人肉搜索、泄露隐私、侮辱诽谤、盗播、侵权

### A.6 迷信 / 封建类

> 《广告法》第九条"含有……迷信……的内容"；《治理规定》第六条（七）[citation:1][citation:22]

- 算命、算卦、占卜、看风水、八字、星座算命
- 招财进宝、旺财、旺夫、提升运气、化解小人、逢凶化吉、时来运转、万事亨通、护身、辟邪、消灾、挡灾
- 神仙、玉皇大帝、如来佛祖、财神、灶神、大仙、鬼怪、报应（用于营销宣传/治病功效宣称）
- 带来好运气、增强第六感、助吉避凶、转富招福

### A.7 谩骂 / 歧视类（不良信息，《治理规定》第七条）

- **地域/民族歧视**：地域黑、民族歧视、种族歧视、性别歧视、地域攻击（如针对特定省份/民族的蔑称）
- **人身攻击/网暴**：侮辱诽谤、造谣、挂人、人身攻击
- **脏话变体**：谐音、拼音、拆字、emoji 组合（需持续补充）

### A.8 谣言 / 虚假信息类（需结合上下文，建议人工复核兜底）

> 《治理规定》第六条（八）[citation:2][citation:22]

- **涉党史国史谣言**：歪曲党史、抹黑英雄烈士、诋毁英烈
- **涉食药卫生谣言**：无科学依据的治病、防癌、特效、神药宣称
- **涉公共政策谣言**：虚构政策、补贴、办事流程
- **涉公共安全谣言**：捏造灾情、警情、伤亡数据
- **伪科普**：打着"科学/养生"旗号的虚假知识

### A.9 方言 / 谐音变体补充（"自定义"分类重点）

> 结合敏感词引擎的"模糊匹配 + 正则"，针对语音转写和方言场景补充：

- **同音近义**：如"最佳/最嘉"、"招财/招才"、"第一/第壹"
- **拼音/缩写**：如 sb、nmsl、wx（引流导流类）
- **方言词**：结合租户行业与地域，由租户管理员在"自定义"中追加（如本地项目名、口头禅）
- **引流导流类**（营销合规）：留微信、加 vx、Q 号、二维码、进群、私信、外链、淘宝店、拼多多、招商、加盟、代理、兼职招聘

### A.10 匹配规则建议（开发落地）

```
1. 精确匹配：政治/涉密、暴恐/违禁（宁可误杀，不可放过）
2. 模糊匹配：色情/低俗、谩骂/歧视（覆盖谐音、变体）
3. 正则匹配：广告极限词（覆盖"最X""第一X"等组合）
4. 方言/谐音：送 ASR 转写 + 模糊匹配，低置信度段标"待人工复核"
5. 图片 OCR：抽出文字后走 1~4，画面违规走独立视觉 API
6. 命中处理：返回 FAIL（附命中词 + 分类 + 位置），调用方统一打回重传
```

### A.11 注意事项

- **语境优先**：部分词（如"最高""第一"）在合理语境下未必违规，建议结合**词边界 + 上下文**判断，避免误杀正常旅游介绍文案。
- **持续运营**：词库需随政策、平台规则动态更新，Admin 提供"导入/导出 + 版本管理"。
- **行业差异**：足浴、研学、疗愈等不同行业可启用不同子集，由租户在"自定义"中叠加。
- **免责**：示例词库仅供参考，最终以**国家法律法规 + 各内容平台最新规则**为准；上线前建议法务复核 [citation:1][citation:2][citation:3]。
