## 〇、版本管控硬约束

> 详见《系统管理》文档。基础版相关要点：
> - 基础版为最低版本，**不能使用**高级版/专业版功能（API/前端/菜单三层拦截）
> - 基础版角色数上限 2 个（`boss` + `employee`），`platform_admin` 不计入
> - 基础版菜单不含 2001~2003/3310~3324/3204~3216 等下移项
> - 基础版预算走**项目级自定义科目** `fee_project_subject`（挂 3201 页内），不依赖系统级三层科目
> - 基础版审批为「极简确认」单级老板审批，不走 Flowable 多级流程
> - 基础版首页为轻量收支概览（本月收入/支出/结余三卡片），不含大类下钻
> - License 未导入的租户降级为基础版默认能力
> - ★PC 端登录租户ID（v2.2 新增）：PC 登录页新增「租户ID」输入框，admin 超管可留空，其他用户必填（向平台管理员获取），tenant_id 由平台管理员分配，租户不可自行生成。前端 login.vue + Vuex + API 已支持透传，后端 LoginBody + SysLoginService 已有租户归属校验。详见《系统管理》开发规范第 9.5 条
> - ★M16/M17 不部署：M16 推广分销与激励为小微版专属，M17 通用评价与点赞仅小微版付费版启用（`FEAT_RATING` 在基础版 disabled），本基础版目录不部署对应脚本、不开放入口
> - ★角色映射数据源（全版本通用，v1.25 补充，与小微版 v1.30 实现对齐）：租户端角色映射页数据源为 `tenant_role_mapping`；本租户映射**全空**时，首次打开列表页按 `sys_tenant.industry` 自动从 admin 在「行业模板管理」维护的行业角色映射（`industry_role_map`）幂等拉取落库（仅空表补录、不覆盖已有映射，遵守 V3.5 §16.4 脱钩原则）；租户只能改名/启停，**不能新建角色 code**
