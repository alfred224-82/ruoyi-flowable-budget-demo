# 多租户 SaaS 平台（小微版）角色菜单终稿 V3.7

> **版本**：V3.7（小微版）  
> **说明**：本文档定义五角色的完整菜单结构。所有讨论结论均已沉淀：  
> - 每个角色均有明确的「默认首页」（🏠 标注）。  
> - **Admin**：平台大盘 + License + 字典（含初始化脚本）。  
> - **租户管理员**：只做「配置自检」，不管业务待办/异常/推广。  
> - **老板**：经营 + 异常处理 + **拉新奖励配置（唯一入口）**。  
> - **员工 / 顾客**：小程序端均有「我的推广码」。

---

## 〇、菜单命名规范（铁律）

1. **系统抽象，行业具象**
   - 菜单层统一使用系统抽象词：员工、房间、活动、任务、固定支出。
   - 行业差异（导游、大巴车、剧本等）仅体现在角色名、项目名、字段文案中。
   - **禁止**为特定行业新增菜单或修改菜单文案。

2. **财务模块命名规范**
   - 小微版仅存在「固定支出」概念。
   - 房租、水电、工资等均为**标签**，而非财务科目。
   - **禁止**出现"固定资产""折旧""摊销""预算"等企业版术语。

3. **周期配置归属**
   - **时间单位（天/周/月/季/年）**：由 Admin 全局定义（数据字典）。
   - **具体周期规则（如：15天、3个月）**：由租户管理员定义并保存，供老板选择。

4. **合规模块归属**
   - **语音合规总开关与底库**：由 Admin 全局控制。
   - **具体录音策略**：由租户管理员配置。
   - **合规记录查看**：由老板查看。

5. **推广模块归属**
   - **我的推广码**：老板、员工、顾客（小程序端）均可见。
   - **拉新奖励配置**：仅老板可配置（唯一入口）。
   - **平台功能总开关**：由 Admin 控制。

## 一、Admin（平台管理员）

**定位**：平台所有者，负责平台级治理。  
**默认首页**：🏠 **平台驾驶舱**

- **🏠 平台驾驶舱（首页）**
  - 租户大盘（总数、活跃度、行业分布）
  - 系统健康度与异常告警
  - 全局合规风险监控
- **License 管理**
  - License 模板管理
  - 租户 License 授权（签发 / 续期 / 禁用）
  - License 使用报表
- **租户管理**
  - 租户列表
  - 新建租户（选择行业 → 自动初始化示例数据，行业创建后不可更改）
  - 租户管理员账号管理
- **全局字典管理**
  - 时间单位字典（天 / 周 / 月 / 季 / 年）
  - 行业类型字典
  - 通用枚举字典
  - *（上线及版本升级时执行**字典初始化脚本**，保证幂等、版本受控）*
- **平台合规（全局）**
  - 语音合规总开关
  - 录音留存策略（全局上限）
  - 平台敏感词库
  - 合规告警看板
- **系统管理**
  - 平台角色管理
  - 平台用户管理
  - 菜单与权限配置
  - 参数配置（含**推广码功能总开关**）
- **运维与审计**
  - 操作日志
  - 登录日志
  - 语音处理日志
  - 数据兜底（手动触发租户重新初始化示例数据）
- **系统监控**
  - 服务健康状态
  - 异常告警

---

## 二、租户管理员（企业配置者）

**定位**：企业管家，负责搭建基础数据与规则，**只做配置自检**。  
**默认首页**：🏠 **企业概览（工作台）**

- **🏠 企业概览（首页 / 工作台）**
  - **企业基本信息**：公司名称、行业、创建时间、**License 有效期与状态**
  - **配置健康度（自检）**：
    - 原子数据完整度（项目 / 房间 / 角色）
    - 周期规则配置状态（老板记账前必须存在可用周期）
    - 语音合规配置状态
  - **系统公告**：平台通知、版本更新
  - **快捷入口**：配置标签、周期、预约策略
  - *（不含任何业务待办 / 异常处理，此类归老板）*
- **原子资源管理**
  - 项目管理
  - 房间 / 空间管理
  - 角色管理
  - 员工库
- **固定支出配置**
  - 标签管理（房租 / 水电 / 工资 等）
  - 周期规则管理（数字 + 单位 → 保存，如"1 个月""15 天"）
- **语音与合规配置**
  - 语音开关（按 Activity 类型，继承行业默认）
  - 敏感词管理（继承平台底库 + 自定义）
  - 录音留存设置（≤ Admin 上限）
  - 转写留痕开关
- **策略开关**
  - 预约策略配置
- **系统设置**
  - 企业信息编辑
  - 安全设置

## 三、老板（经营者）

**定位**：企业所有者，负责经营决策、异常处理、推广奖励配置。  
**默认首页**：🏠 **经营驾驶舱**

- **🏠 （首页）**
  - **核心经营数经营驾驶舱据**：今日 / 本月营收、支出、净利润
  - **成本构成**：按标签（房租 / 水电等）占比
  - **业务待办与异常处理中心**（核心入口）：
    - 预约冲突处理
    - 预约失败通知（RESERVATION_FAILED，支持一键重新预约，自动带入原参数并高亮冲突点）
    - 语音合规命中记录
    - 固定支出异常提醒
- **推广管理**
  - **拉新奖励配置**（唯一配置入口）
    - 开启 / 关闭拉新奖励
    - 奖励形式（金额 / 抵扣券 / 积分）
    - 触发条件（新客绑定 / 新客首单，二选一）
    - 奖励上限设置（可选）
  - **推广数据看板**
    - 拉新排行榜
    - 推广奖励发放记录
- **活动 / 预约管理**
  - 活动列表
  - 预约看板
- **数据与报表**
  - **固定支出管理**（记账入口：选标签 + 选周期规则 + 填金额，系统自动分摊）
  - 语音合规记录（只读）
  - 员工业绩榜
  - 
  - 评价管理
- **我的**
  - 消息通知
  - 账号设置

## 七、首页与职责边界（铁律）

| 角色 | 默认首页 | 核心职责 |
|---|---|---|
| **Admin** | 平台驾驶舱 | 平台治理、License、字典、大盘监控 |
| **租户管理员** | 企业概览（工作台） | **配置自检**（原子数据 / 周期 / 合规） |
| **老板** | 经营驾驶舱 | **经营决策 + 业务异常处理 + 拉新奖励配置** |
| **员工** | 工作台 | 任务执行 + 我的推广码 |
| **顾客** | 发现页 | 消费预约 + 我的推广码（邀请有礼） |

**职责边界铁律：**
1. **租户管理员**：只关心"配置对不对"，**不处理**业务待办与预约异常，**不配置推广奖励**。
2. **老板**：只关心"生意好不好"，**全权处理**业务待办与异常，**唯一**拥有拉新奖励配置权。
3. **员工 / 顾客**：小程序端均可查看"我的推广码"，仅查看本人推广记录与奖励，**不可配置**。
4. **Admin**：只管平台级，不碰租户具体业务数据；字典通过初始化脚本统一管理。

    - 触发条件（新客绑定 / 新客首单，二选一）
    - 奖励上限设置（可选）
  - **推广数据看板**
    - 拉新排行榜
    - 推广奖励发放记录
- **活动管理**
  - 活动列表

**免费版不含（升级后解锁）：**
- ❌ 经营驾驶舱（付费版首页）
- ❌ 预约看板
