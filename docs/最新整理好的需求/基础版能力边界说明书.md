# 基础版能力边界说明书

> 版本：v1.0  日期：2026-09-16  
> 依据：《资金管控系统开发任务文档》v1.24 T5.19  
> 适用范围：基础版（basic）全部功能模块

---

## 一、基础版定位

基础版面向**中小型企业项目资金管理**场景，提供轻量记账 + 项目资金流 + 全量业态能力。
角色收敛为 **boss / employee** 两角色，审批为极简单级老板审批。

**与小微版的核心区别**：
- 小微版 = 门店经营（预约/服务/推广/评价）
- 基础版 = 项目资金（立项/收款/付款/报销/收入确认）

| 模块 | 能力项 | 说明 |

## 三、基础版不包含能力（高级版+专属）

| 能力 | 所属版本 | 说明 |
|------|---------|------|
| 部门级预算 | V3 高级版 | 基础版仅公司级 |
| 报销管控（发票验真） | V3 高级版 | 基础版不做发票校验 |
| 烂账/隐形成本 | V3 高级版 | 基础版不含 |
| 自定义规则引擎 | V3 高级版 | 基础版使用预设规则 |
| 利润报表 | V3 高级版 | 基础版仅基础收支报表 |
| 凭证导出 7 套模板 | V3 高级版 | 基础版仅通用导出 |
| 打卡/信用/部门预算 | V3 高级版（M6 增量） | 基础版不含 |
| 多组织 | V4 专业版 | 基础版单组织 |
| 多账套 | V4 专业版 | 基础版单账套 |
| 物理隔离 | V4 专业版 | 基础版共享数据库 |
| 人脸比对 | V4 专业版 | 基础版不含 |
| 二维导出 | V4 专业版 | 基础版仅标准导出 |

---

## 四、角色权限矩阵

| 角色 | 可用功能 | 审批权限 |
|------|---------|---------|
| boss | 全部功能 + 审批 + 配置 | 报销/付款/收入确认 单级审批 |
| employee | 报销提交 + 消息查看 + 项目查看 | 无审批权 |

**约束**：
- 基础版禁止新增角色 code（sys_role 不可扩展）
- boss 不可审批自己提交的报销单

---

## 五、数据隔离

- 基础版为**逻辑隔离**（tenant_id），非物理隔离
- 全部业务表含 tenant_id + 租户索引
- 多租户插件自动过滤

---

## 六、升级路径

```
基础版(V2) ──→ 高级版(V3) ──→ 专业版(V4) ──→ 企业版(V5)
   │              │              │              │
   预算管控       发票验真        多组织          物理隔离
   规则引擎       利润报表        多账套          定制开发
                  凭证模板        开放平台增强     SLA保障
```
