**V1 关键约束**：
- 零支付合规：禁止任何支付 SDK，仅"标记已线下发放"记账口径
- 推广码永久一人一码，归因只认最后扫码
- 评价针对 User 非角色，禁止自评
- 小程序 = 单一壳 + 区块配置
