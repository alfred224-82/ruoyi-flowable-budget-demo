## 1. 系统概述与版本能力

### 1.1 企业专业版定位

企业专业版是费用管控系统的最高版本，面向集团型企业，提供完整的预算全生命周期管理能力。相比基础版和高级版，企业专业版新增以下核心能力：

| 能力维度 | 基础版 | 高级版 | 企业专业版 |
|---------|--------|--------|-----------|
| 审批层级 | 固定单级 | 1~N级可配 | 三级审批（部门→分公司→总公司） |
| 资金池 | 无 | 部门级单层 | 部门/分公司/总公司三级资金池 |
| 费用确认方式 | 仅直接费用化 | 折旧+摊销 | 折旧+摊销+费率利息（完整四轨） |
| 跨部门分摊 | 不支持 | 不支持 | 支持（按人数/面积/收入） |
| 报表分析 | 不支持 | 不支持 | 盈利分析+异常监控 |
| AI能力 | 不支持 | AI对话填报 | AI私有化部署+智能审批摘要 |
| 预算审批 | 不支持 | 不支持 | 完整预算审批流程 |

### 1.2 角色体系

企业专业版采用四级角色体系：

| 角色标识 | 角色名称 | 职责 |
|---------|---------|------|
| `deptPlan` | 部门预算编制人员 | 编制预算、提交报销、申请预算调整 |
| `deptManager` | 部门经理 | 第1级审批，管理本部门资金池 |
| `branch` | 分公司本部 | 第2级审批，管理分公司资金池 |
| `headquarters` | 总公司本部 | 第3级审批，管理总公司资金池 |

### 1.3 核心业务主线

```
系统初始化 → 预算编制 → 费用管控 → 预算调整 → 报表分析
```

## 2. 租户与多租户管理

### 2.1 多租户模式说明

本系统采用 **SaaS 多租户架构**，支持多家企业（租户）共享同一套系统部署，各租户之间数据完全隔离。

**核心机制：**
- 每个企业作为一个独立「租户」接入系统
- 所有业务数据（预算、报销、科目、映射规则、福利政策、资金池、分摊规则等）通过 `tenant_id` 字段实现行级隔离
- 租户A的用户无法看到或操作租户B的任何数据
- 超级管理员（admin）不受租户隔离限制，可跨租户管理

### 2.2 租户信息

每个租户包含以下基本信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| 租户编码 | 唯一标识（不可修改） | T0001 |
| 企业名称 | 公司全称 | XX集团科技有限公司 |
| 联系人 | 业务对接人 | 张三 |
| 联系电话 | — | 138xxxx0001 |
| 行业 | 所属行业 | 制造业 |
| 规模 | SMALL/MEDIUM/LARGE | LARGE |
| 分配版本 | BASIC/ADVANCED/ENTERPRISE | ENTERPRISE |
| 授权类型 | TRIAL（试用）/FORMAL（正式） | FORMAL |
| 授权到期日 | 授权有效期 | 2028-12-31 |
| 最大用户数 | 允许创建的用户上限 | 200 |
| 功能开关 | JSON格式的功能开关列表 | ["FEE_MULTI_CURRENCY",...] |
| 状态 | PENDING/NORMAL/DISABLED/EXPIRED | NORMAL |

### 2.3 租户生命周期

```
PENDING（待激活）→ NORMAL（正常使用）→ DISABLED（已停用）
                                      → EXPIRED（已过期）
```

| 状态 | 说明 |
|------|------|
| PENDING | 租户已创建，尚未激活使用 |
| NORMAL | 正常使用中 |
| DISABLED | 平台管理员手动停用，所有用户无法登录 |
| EXPIRED | 授权到期，系统自动标记 |

### 2.4 租户管理员操作（平台管理员）

租户管理功能仅对拥有 `platform_admin` 角色的平台管理员可见。

**操作路径：** 系统管理 → 租户管理 → 租户列表

#### 2.4.1 创建租户

1. 进入「租户管理 → 租户列表」
2. 点击「新增」
3. 填写租户信息：
   - 租户编码（唯一，如：T0002）
   - 企业名称
   - 联系人、联系电话
   - 选择行业、规模
   - 选择分配版本（基础版/高级版/企业版）
   - 设置授权类型（试用/正式）
   - 设置授权到期日
   - 设置最大用户数
4. 点击「确定」
5. 系统自动：
   - 创建租户管理员账号
   - 初始化默认角色
   - 记录版本分配日志
   - 根据版本启用对应功能开关

#### 2.4.2 启用/停用租户

1. 在租户列表找到目标租户
2. 点击「状态」开关
3. 停用后，该租户所有用户将无法登录系统
4. 重新启用后恢复正常

#### 2.4.3 版本分配与升级

1. 在租户列表点击「分配版本」
2. 选择目标版本（BASIC → ADVANCED → ENTERPRISE）
3. 确认后系统：
   - 更新租户版本字段
   - 记录版本变更日志（含变更类型：INIT/UPGRADE/DOWNGRADE）
   - 刷新功能开关缓存（通过Redis发布订阅通道）
4. 租户用户下次登录即生效新版本功能

**版本变更日志：**

| 字段 | 说明 |
|------|------|
| 变更前版本 | 原版本 |
| 变更后版本 | 新版本 |
| 变更类型 | INIT（初始化）/UPGRADE（升级）/DOWNGRADE（降级） |
| 操作人 | 执行操作的管理员 |
| 时间 | 变更时间 |

#### 2.4.4 用量统计

平台管理员可查看每个租户的用量信息：
- 当前用户数 / 最大用户数
- 版本变更次数
- 配置项数量
- 当前版本与状态

### 2.5 租户数据隔离范围

以下业务数据均按租户隔离，各租户互不可见：

| 数据类型 | 隔离表 |

### 2.6 租户级功能配置

平台管理员可为每个租户单独配置功能参数：

| 配置键 | 说明 | 示例值 |
|--------|------|--------|
| approval_flow | 审批流程配置 | JSON |
| welfare_policy | 福利政策配置 | JSON |
| subject_system | 科目体系配置 | JSON |

**操作路径：** 租户详情 → 功能配置

### 2.7 福利政策配置（租户级）

企业版支持按租户配置公司福利政策，用于报销时自动计算补助金额：

| 字段 | 说明 |
|------|------|
| 福利编码 | 租户内唯一 |
| 福利名称 | 如：工作日餐补 |
| 福利大类 | MEAL/TRAVEL/TRANSPORT/OTHER |
| 福利子类 | WORKDAY_MEAL/OVERTIME_MEAL/SHORT_TRIP/LONG_TRIP等 |
| 适用区域 | DOMESTIC/INTERNATIONAL/ALL |
| 出差时长类型 | SHORT/LONG/ANY |
| 城市等级 | TIER1/TIER2/TIER3/ANY（仅国内） |
| 国家分组 | HK_MO_TW/ASIA/EUROPE_AMERICA/OTHER/ANY（仅国外） |
| 补助标准金额 | 如：100元/天 |
| 计量单位 | DAY/MONTH/TIME/MEAL |
| 最大享受天数 | 0=不限 |
| 适用职级 | ALL/指定职级 |
| 生效日期/失效日期 | 控制有效期 |
| 状态 | ENABLED/DISABLED |

### 2.8 企业版租户注意事项

- 企业版租户最大用户数默认为 **200人**
- 试用授权到期后状态自动变为 EXPIRED，需联系平台管理员续期
- 企业版支持全部功能开关，含12项企业版专属开关
- 福利政策支持国内/国外双维度配置（城市等级 + 国家分组）
- 集团型企业可为每个分公司创建独立租户，实现数据完全隔离
- 版本升级零迁移：替换配置 → 执行增量SQL → 重启服务

## 3. 系统初始化

### 3.1 初始化概述

企业专业版支持完整的三条工作流配置和三级资金池体系。系统初始化是上线前的关键步骤，决定了后续所有业务流程的运转方式。

### 3.2 工作流配置

企业专业版支持配置以下三条工作流，每条工作流可设置1~N级审批：

#### 2.2.1 预算编制审批工作流

**配置路径：** 费用管理 → 系统初始化 → 工作流配置

**推荐配置（三级审批）：**

| 审批级别 | 审批角色 | 说明 |
|---------|---------|------|
| 第1级 | 部门经理（deptManager） | 审核本部门预算编制的合理性 |
| 第2级 | 分公司本部（branch） | 审核分公司整体预算平衡 |
| 第3级 | 总公司本部（headquarters） | 终审，通过后预算锁定 |

**操作步骤：**
1. 进入「工作流配置」页面
2. 选择「预算编制审批」工作流
3. 设置审批级数为 3
4. 依次配置每级审批角色
5. 保存配置

#### 2.2.2 报销审核工作流

**推荐配置：**

| 审批级别 | 审批角色 | 说明 |
|---------|---------|------|
| 第1级 | 部门经理 | 审核报销单真实性与合规性 |
| 第2级 | 分公司财务 | 复核金额与科目归属 |

#### 2.2.3 预算调整审批工作流

**推荐配置（三级审批）：**

| 审批级别 | 审批角色 | 说明 |
|---------|---------|------|
| 第1级 | 部门经理 | 审批调整申请，扣减部门资金池差额 |
| 第2级 | 分公司本部 | 向上级资金池分摊总额 |
| 第3级 | 总公司本部 | 终审，完成资金池分摊 |

### 3.3 三级资金池配置

企业专业版支持部门/分公司/总公司三级资金池体系：

| 资金池层级 | 默认初始额度 | 用途 |
|-----------|-------------|------|
| 部门资金池（DEPT） | 10万元 | 部门级预算调整审批时扣减差额 |
| 分公司资金池（BRANCH） | 50万元 | 分公司级预算调整审批时分摊总额 |
| 总公司资金池（HQ） | 100万元 | 总公司级预算调整审批时分摊总额 |

**配置步骤：**
1. 进入「费用管理 → 资金池管理」
2. 点击「新增资金池」
3. 选择层级类型（部门/分公司/总公司）
4. 设置初始额度（系统已预填默认值）
5. 关联对应组织部门
6. 保存

> **说明：** 资金池初始额度在编制开始时由上级分摊设定，后续支持通过预算调整流程继续申请。若系统中无对应层级资金池记录，审批时会自动按默认额度创建。

### 3.4 预算科目配置

**配置路径：** 费用管理 → 预算科目

预算科目是预算编制和费用管控的基础数据，企业专业版按财务六大科目分类：

| 会计大类 | 说明 | 示例 |
|---------|------|------|
| 资产类 | 含固定资产，每月折旧 | 办公设备、车辆 |
| 负债类 | 借款等 | 贷款利息 |
| 所有者权益 | — | — |
| 收入类 | — | — |
| 费用类 | 日常运营支出 | 差旅费、办公费 |
| 利润类 | — | — |

**操作步骤：**
1. 进入「预算科目」页面
2. 点击「新增科目」
3. 填写科目编码、科目名称
4. 选择所属会计大类
5. 设置科目类型（预算科目/核算科目）
6. 保存

### 3.5 映射规则配置

映射规则决定了报销时如何自动匹配预算科目，是费用管控的核心配置。

**配置路径：** 费用管理 → 映射规则

**规则字段说明：**

| 字段 | 说明 |
|------|------|
| 物资小类编码 | 报销费用的分类（如：办公用品、差旅交通） |
| 用途标签编码 | 费用用途（如：日常办公、项目交付） |
| 目标预算科目 | 匹配后归入的预算科目 |
| 归属会计大类 | 费用确认的会计分类 |
| 费用确认方式 | DIRECT/DEPRECIATION/ACCRUAL/FEE_RATE |
| 是否固定资产 | 标记是否需要填写使用年限 |
| 优先级 | 数值越大优先级越高 |

**企业专业版支持四种费用确认方式：**

| 确认方式 | 编码 | 说明 | 适用场景 |
|---------|------|------|---------|
| 直接费用化 | DIRECT | 一次性计入当期费用 | 日常办公费、差旅费 |
| 折旧 | DEPRECIATION | 按使用年限按月折旧 | 固定资产（设备、车辆） |
| 计提摊销 | ACCRUAL | 按摊销期数按月分摊 | 长期待摊费用（装修） |
| 费率利息 | FEE_RATE | 系统按月自动计提利息 | 贷款利息（企业版专属） |

### 3.6 用途标签配置

**配置路径：** 费用管理 → 用途标签

用途标签用于标记报销费用的具体用途，与物资小类组合后触发映射规则。

### 3.7 成本中心配置

**配置路径：** 费用管理 → 成本中心

成本中心用于跨部门费用分摊的归集管理：

| 字段 | 说明 |
|------|------|
| 中心编码 | 唯一标识 |
| 中心名称 | 成本中心名称 |
| 默认会计大类 | EXPENSE/ASSET/COST |
| 待分摊中心 | 标记该中心费用是否需要跨部门分摊 |
| 状态 | 启用/停用 |

### 3.8 分摊规则配置

**配置路径：** 费用管理 → 费用分摊

企业专业版支持跨部门费用分摊，需预先配置分摊规则：

| 字段 | 说明 |
|------|------|
| 规则名称 | 如"行政费用按人数分摊" |
| 分摊方法 | HEAD_COUNT（按人数）/WORK_HOUR（按工时）/RATIO（按比例） |
| 目标部门 | 分摊至哪个部门 |
| 权重 | 分摊权重（所有启用规则的权重之和为分母） |
| 状态 | 启用/停用 |

## 4. 预算编制

### 4.1 编制流程概述

预算编制采用向导式三步流程：

```
第一步：基础信息 → 第二步：科目预算编制 → 第三步：预览提交
```

**流程规则：**
- 新增编制：从第一步开始
- 修改编制（被驳回后）：从第二步开始，不可返回第一步
- 查看模式：直接进入第三步

### 4.2 场景一：新年度首次编制

#### 第一步：填写基础信息

1. 进入「费用管理 → 预算编制」
2. 点击「新增编制」
3. 填写基础信息：
   - 编制年度
   - 编制月份
   - 所属部门（自动填充当前用户部门）
   - 编制说明

#### 第二步：科目预算编制

1. 系统自动加载所有启用的预算科目
2. **数据初始化**（企业专业版智能填充）：
   - 系统自动查询本部门上月已审批通过的报销单数据
   - 按预算科目分组汇总，填充至对应科目的初始化金额
   - 若某科目上月无报销数据，自动回退至上月预算金额
   - 页面提示："已加载上月报销实际数据（N个科目），请根据本月计划调整"
   - 数据源标记为 MIXED（混合数据源）
3. 逐科目填写本月预算金额
4. 对于资产类科目，必须填写使用年限（折旧年限）
5. 点击「下一步」，系统保存所有科目金额至明细表

> **跨年处理：** 若当前为1月，系统自动计算上年12月作为"上月"进行数据加载。

#### 第三步：预览与提交

1. 预览所有科目预算汇总表
2. 确认无误后点击「完成编制」
3. 预算单状态变为 `Completed`
4. 点击「提交审核」，进入审批流程

### 4.3 场景二：被驳回后修改重新提交

**驳回规则：**
- 任何一级审批驳回，均回退至编制人员
- 驳回时必须填写驳回原因
- 驳回后预算单状态变为 `Rejected`

**重新提交流程：**
1. 编制人员收到驳回通知
2. 进入预算编制列表，找到被驳回的预算单
3. 点击「修改」，系统从第二步（科目预算编制）进入
4. 根据驳回原因调整预算金额
5. 点击「完成编制」→「提交审核」
6. **关键规则：** 重新提交后从被驳回的审批级别继续，不回退到已通过的级别

**示例：**
- 被分公司驳回 → 重新提交后直接从分公司领导审批开始
- 被总公司驳回 → 重新提交后直接从总公司领导审批开始

### 4.4 场景三：审批流程（审批人视角）

#### 部门经理审批（第1级）

1. 部门经理登录系统
2. 进入「费用管理 → 预算审核」
3. 查看待审批预算单列表
4. 点击预算单进入详情
5. 审核各科目预算金额合理性
6. 操作选择：
   - **通过：** 流转至分公司领导
   - **驳回：** 必须填写驳回原因，回退至编制人员
   - **批量通过：** 支持勾选多条一键通过

#### 分公司领导审批（第2级）

1. 分公司领导登录系统
2. 进入「预算审核」
3. 审核分公司下属各部门预算汇总
4. 通过/驳回操作

#### 总公司领导审批（第3级）

1. 总公司领导登录系统
2. 进入「预算审核」
3. 终审全公司预算
4. **通过后：** 预算状态锁定，不可再编制修改

### 4.5 预算编制状态流转

```
Draft（草稿）→ Completed（完成编制）→ Pending_Dept_Review（部门审核中）
→ Pending_Branch_Review（分公司审核中）→ Pending_HQ_Review（总公司审核中）
→ Approved（已通过）

任何审核中状态 → Rejected（已驳回）→ 修改后重新提交
```

## 5. 费用管控（报销管理）

### 5.1 报销流程概述

企业专业版报销单采用**一步式提交**：
- 创建即提交，无草稿状态
- 无删除功能
- 状态机：`SUBMITTED`（正常提交）或 `OVER_BUDGET_PENDING`（超预算待审）

### 5.2 场景一：AI对话式填报（推荐）

企业专业版提供AI对话流引导填报，共9步：

| 步骤 | 内容 | 说明 |
|------|------|------|
| 1 | 选择消费大类 | 如：办公用品、差旅交通、固定资产 |
| 2 | 选择物资小类 | 如：打印纸、机票、电脑设备 |
| 3 | 选择用途标签 | 如：日常办公、项目交付 |
| 4 | 选择币种 | CNY/USD/EUR等（多币种支持） |
| 5 | 输入金额 | 提示动态带币种符号 |
| 6 | 费用确认方式确认 | 系统根据映射规则自动判断 |
| 7 | 补充信息 | 根据确认方式动态分支（见下表） |
| 8 | 选择报销年月 | — |
| 9 | 确认提交 | 预览后一步提交 |

**费用确认方式动态分支（企业版完整支持）：**

| 确认方式 | 额外步骤 |
|---------|---------|
| DIRECT（直接费用化） | 无额外步骤 |
| DEPRECIATION（折旧） | 输入折旧年限（年） |
| ACCRUAL（计提摊销） | 输入摊销期数（月） |
| FEE_RATE（费率利息） | 显示"利息由系统按月自动计提"提示 |

### 5.3 场景二：手动表单填报

1. 进入「费用管理 → 费用报销」
2. 点击「新增报销单」
3. 填写表单：
   - 物资小类（下拉选择）
   - 用途标签（下拉选择）
   - 项目编号（非必填）
   - 报销金额
   - 币种（默认CNY）
   - 费用发生日期（默认当天，隐藏字段）
4. 系统自动执行映射规则匹配：
   - 根据「物资小类 + 用途标签」查询映射规则
   - 自动填充预算科目和会计大类
   - 展示预算归属预览（含科目名称与可用余额）
5. 若为固定资产，填写使用年限（必填）
6. 点击「提交」

### 5.4 场景三：超预算报销

当报销金额超过对应预算科目可用余额时：

1. 系统自动检测超预算
2. 报销单状态变为 `OVER_BUDGET_PENDING`（超预算待审）
3. 系统自动创建超预算审批单
4. 进入超预算审批流程：
   - 审批人可查看该科目当前预算金额、已用金额、本次报销金额
   - 审批人可选择：
     - **通过：** 报销单生效，扣减预算余额
     - **驳回：** 报销单作废
     - **调整科目预算：** 直接调增该科目预算额度后通过

### 5.5 场景四：多币种报销

企业专业版支持多币种报销：

1. 在AI对话流第4步或手动表单中选择币种
2. 系统自动获取汇率进行换算
3. 报销单记录原币金额（originalAmount）和人民币金额（amount）
4. 预算扣减以人民币金额为准

### 5.6 场景五：月末跨部门费用分摊

企业专业版支持月末自动执行跨部门费用分摊：

**前置条件：**
- 已配置分摊规则（含目标部门和权重）
- 存在待分摊的已审批报销单（allocation_status = PENDING）

**执行步骤：**
1. 进入「费用管理 → 费用分摊」
2. 点击「执行分摊」
3. 选择分摊期间（月份）
4. 选择来源部门
5. 选择分摊基准（按人数/按面积/按收入）
6. 确认执行

**分摊逻辑：**
- 系统查询该月所有待分摊的已审批报销单
- 按启用规则的权重比例计算各部门分摊金额
- 最后一个部门取差额（避免精度丢失）
- 更新报销单分摊状态为 `ALLOCATED`

### 5.7 报销审批（审批人视角）

1. 审批人进入「费用管理 → 报销审批」
2. 查看待审批报销单列表
3. 点击报销单查看详情：
   - 报销人、部门
   - 物资小类、用途标签
   - 金额、币种
   - 归属预算科目及可用余额
   - 支出类型标签
4. 审批操作：通过/驳回

## 6. 预算调整

### 6.1 调整流程概述

当实际业务需要超出原预算时，编制人员可发起预算调整申请。企业专业版采用三级审批+资金池差额分摊机制。

### 6.2 场景一：编制人员发起预算调整申请

**操作步骤：**
1. 进入「费用管理 → 预算调整」
2. 点击「新增申请」
3. 填写申请信息：
   - 选择物资小类（与报销单一致）
   - 选择用途标签
   - 系统自动匹配目标预算科目（通过映射规则）
   - 展示预算归属预览（科目名称 + 当前可用余额）
   - 输入申请金额（调整后的目标金额）
   - 填写调整原因
4. 提交申请

**申请提交后：**
- 申请单状态变为「部门审批中」
- 编制人员可在列表查看自己提交的申请（按申请人过滤）
- 审批中状态可执行「取消」操作

### 6.3 场景二：部门经理审批（第1级）

**审批页面信息：**
- 申请单号、申请人、目标科目
- 申请金额（目标金额）
- 预算可用余额（当前余额）
- 当前层级、部门名称
- 资金池信息（当前部门资金池总额/已分摊/可用）

**差额分摊逻辑：**
```
差额（allocateAmount）= 申请金额 - 预算可用余额
```

**审批操作：**
- **通过：**
  - 系统从部门资金池扣减差额
  - 目标科目余额更新为申请金额
  - 申请单流转至分公司审批
- **驳回：**
  - 必须填写驳回原因
  - 预算余额和资金池不变
  - 编制人员可修改后从部门级别重新审批

**资金池不足处理：**
- 若部门资金池可用余额不足以覆盖差额
- 系统提示预警信息
- 审批人可选择驳回或继续（触发上级资金池支持）

### 6.4 场景三：分公司领导审批（第2级）

**审批逻辑：**
- 分公司审批仅对上级资金池分摊总额
- 不再重复扣减部门资金池

**审批操作：**
- **通过：** 从分公司资金池分摊，流转至总公司
- **驳回：** 回退至编制人员，可从分公司级别重新提交

### 6.5 场景四：总公司领导审批（第3级）

**审批操作：**
- **通过：**
  - 从总公司资金池分摊
  - 申请单状态变为「已通过」
  - 系统立即更新 `budget_preparation_detail.budget_amount` 为申请金额
  - 此后所有可用余额计算均基于更新后的 budget_amount
- **驳回：** 回退至编制人员

### 6.6 场景五：审批通过后预算生效

预算调整审批全部通过后：
1. 系统自动调用 `setBudgetAmount` 方法
2. 将预算编制明细表的 `budget_amount` 更新为申请金额
3. 所有后续的可用余额计算、预算校验均只依赖更新后的数据
4. 不再关联或查询调整表

### 6.7 资金池自动创建机制

若审批时对应层级无资金池记录：
- 系统自动创建默认资金池：
  - 部门：10万元
  - 分公司：50万元
  - 总公司：100万元
- 将创建的 reservedId 回写至申请单

### 6.8 预算调整状态流转

```
部门审批中(DEPT_APPROVING) → 分公司审批中(BRANCH_APPROVING) 
→ 总公司审批中(HQ_APPROVING) → 已通过(APPROVED)

任何审批中 → 已驳回(REJECTED) → 可修改重提
任何审批中 → 已撤回(CANCELLED)（申请人主动取消）
```

## 7. 报表分析

### 7.1 盈利分析表

**配置路径：** 费用管理 → 报表分析

企业专业版提供完整的盈利分析能力，按财务六大科目维度分析预算执行情况。

#### 6.1.1 明细视图

按「组织机构 + 预算科目」分组展示：

| 列 | 说明 |
|----|------|
| 预算科目编码 | 科目唯一标识 |
| 预算科目名称 | 科目中文名 |
| 会计大类 | 六大科目分类 |
| 实际金额 | 已审批通过的报销总额 |
| 预算金额 | 编制/调整后的预算总额 |
| 差异金额 | 预算 - 实际（正数=结余，负数=超支） |
| 差异率 | 差异金额 / 预算金额 × 100% |

**筛选条件：**
- 组织机构（树形选择，不选则查全部）
- 年度（必选）
- 月份（不选则全年汇总）

#### 6.1.2 汇总视图

按会计六大科目聚合展示全公司预算执行概况：

| 会计大类 | 实际金额 | 预算金额 | 差异金额 | 差异率 |
|---------|---------|---------|---------|--------|
| 资产类 | ¥xxx | ¥xxx | ¥xxx | xx% |
| 费用类 | ¥xxx | ¥xxx | ¥xxx | xx% |
| ... | ... | ... | ... | ... |

**颜色标识：**
- 绿色：差异金额 > 0（预算有结余）
- 红色：差异金额 < 0（超预算）
- 灰色：差异金额 = 0（持平）

### 7.2 预算归属异常监控表

用于监控预算归属异常的报销单据：

**配置路径：** 费用管理 → 报表分析 → 异常监控

展示无法正确匹配预算科目或存在归属争议的报销记录，便于财务人员及时纠正。

### 7.3 AI审批摘要报告

企业专业版支持AI自动生成预算审批摘要报告：

| 报告内容 | 说明 |
|---------|------|
| 预算单总数 | 本批次审批的预算单数量 |
| 预算总额 | 所有预算单金额合计 |
| 实际总额 | 已执行金额合计 |
| 差异金额 | 预算总额 - 实际总额 |
| 平均差异率 | 整体预算执行偏差 |

## 8. 常见场景操作指南

### 8.1 场景：新公司上线初始化

**完整初始化清单：**

| 序号 | 配置项 | 操作路径 | 必要性 |
|------|--------|---------|--------|
| 1 | 配置预算科目 | 预算科目管理 | 必须 |
| 2 | 配置映射规则 | 映射规则管理 | 必须 |
| 3 | 配置用途标签 | 用途标签管理 | 必须 |
| 4 | 配置工作流（3条） | 系统初始化 | 必须 |
| 5 | 配置三级资金池 | 资金池管理 | 推荐 |
| 6 | 配置成本中心 | 成本中心管理 | 按需 |
| 7 | 配置分摊规则 | 费用分摊 | 按需 |
| 8 | 配置补助标准 | 补助标准管理 | 按需 |

### 8.2 场景：月度预算编制闭环

```
月初 → 编制人员新建预算（自动加载上月实绩）
     → 调整各科目标金额
     → 完成编制 → 提交审核
     → 部门经理审批 → 分公司审批 → 总公司审批
     → 预算生效
月末 → 执行跨部门费用分摊
     → 查看盈利分析报表
```

### 8.3 场景：固定资产采购报销

1. 发起报销，选择消费大类「固定资产」
2. 选择物资小类（如：电脑设备）
3. 选择用途标签（如：日常办公）
4. 系统映射规则匹配：
   - 费用确认方式 = DEPRECIATION
   - 是否固定资产 = 是
5. AI对话流提示输入「折旧年限」
6. 输入使用年限（如：5年）
7. 系统按月自动计算折旧额 = 金额 / (使用年限 × 12)
8. 折旧额纳入盈利分析表的资产类科目

### 8.4 场景：贷款利息按月计提（企业版专属）

1. 发起报销，选择对应物资小类和用途标签
2. 映射规则匹配费用确认方式 = FEE_RATE
3. AI对话流显示提示："利息由系统按月自动计提"
4. 无需手动输入期数
5. 系统按月自动生成计提记录

### 8.5 场景：预算不足需要调整

**完整流程：**
1. 编制人员发现某科目预算不足
2. 进入「预算调整」→「新增申请」
3. 选择物资小类 + 用途标签 → 系统自动定位目标科目
4. 查看当前可用余额，输入目标金额
5. 提交 → 部门经理审批（扣减资金池差额）
6. → 分公司审批（分摊总额）
7. → 总公司审批（分摊总额）
8. → 审批通过 → 科目余额自动更新为目标金额
9. 后续报销即可使用新额度

### 8.6 场景：集团跨部门费用分摊

**适用情况：** 行政部门统一采购的办公用品需分摊至各业务部门

1. 确保已配置分摊规则：
   - 规则A：分摊至销售部，权重 40%
   - 规则B：分摊至研发部，权重 35%
   - 规则C：分摊至运营部，权重 25%
2. 月末进入「费用分摊」
3. 选择分摊期间（如 2026-07）
4. 选择来源部门（行政部）
5. 选择分摊基准（按人数）
6. 点击执行
7. 系统自动：
   - 查询行政部当月待分摊报销单
   - 按权重比例计算各部门分摊金额
   - 生成分摊记录
   - 更新报销单状态为已分摊

### 8.7 场景：查看预算执行情况

1. 进入「报表分析 → 盈利分析」
2. 选择视图类型：
   - 明细视图：查看每个科目的执行详情
   - 汇总视图：查看六大科目整体概况
3. 选择组织机构（或全部）
4. 选择年度和月份
5. 点击查询
6. 关注红色标记的超支科目
7. 可导出报表用于汇报
