## 一、系统概述与版本说明

本系统提供 **三个版本等级**，所有版本共用一套系统，差异仅通过功能开关控制，升级无需重新部署。

| 版本 | 编码 | 适用场景 | 核心能力 |
|------|------|----------|----------|
| 基础版 | BASIC | 小型团队 | 预算编制+单级审批、费用报销、基础预算校验 |
| 高级版 | ADVANCED | 中型企业 | +可配置多级审批、超预算审批、资金池、预算调整、合规引擎、多币种、三轨管控 |
| 企业版 | ENTERPRISE | 集团企业 | +三级审批、三级资金池、报表分析、AI智能、计提引擎、跨部门分摊 |

## 二、版本升级指南

### 2.1 升级操作步骤（网页操作）

**前提条件**：已获取对应版本的正式License（联系厂商获取）。

**操作步骤**：

1. 使用 **管理员账号（admin）** 登录系统；
2. 点击左侧菜单：**系统管理 → License管理**；
3. 页面展示当前授权信息（版本等级、到期时间、已启用功能数）；
4. 点击右上角 **「切换版本」** 按钮；
5. 在弹窗中选择目标版本：
   - 基础版 → 选择 `ADVANCED`（高级版）
   - 高级版 → 选择 `ENTERPRISE`（企业版）
6. 点击 **「确定」**，系统即时生效，**无需重启服务**；
7. 刷新页面（F5），新增功能菜单自动出现。

> 💡 **提示**：如需申请正式License，点击 **「导出机器指纹」** 按钮，将指纹信息发送给厂商即可获取授权文件。

### 2.2 基础版 → 高级版：升级后新增什么

| 新增能力 | 菜单入口 | 升级后需要做什么 |
|----------|----------|------------------|
| 可配置审批流 | 费用管控 → 系统初始化 | 配置预算编制/报销/调整工作流审批节点 |
| 超预算审批 | 费用管控 → 超预算审批 | 无需配置，自动生效 |
| 预算调整+资金池 | 费用管控 → 预算调整申请 / 资金池管理 | 在系统初始化中配置资金池额度 |
| 报销审批列表 | 费用管控 → 报销单审批 | 给部门经理角色分配该菜单权限 |
| 用途标签/映射规则 | 费用管控 → 用途标签管理 / 映射规则管理 | 按业务需要维护标签和映射规则 |
| 成本中心 | 费用管控 → 成本中心 | 维护部门-成本中心对应关系 |
| 操作日志 | 费用管控 → 操作日志 | 自动记录，无需配置 |
| 合规引擎自定义 | 费用管控 → 合规配置 | 按科目设置合规级别 |
| 多币种 | 费用管控 → 汇率管理 | 维护月度汇率 |
| 三轨管控 | 费用管控 → 三轨管控配置 | 分配科目到轨道 |

**升级后建议操作顺序**：
1. 进入「系统初始化」配置工作流（可跳过，使用默认流程）；
2. 配置资金池初始额度；
3. 在「角色管理」中为部门经理分配新增菜单权限；
4. 维护用途标签和映射规则。

| 场景 | 说明 |
|------|------|

| 降级 | 高级功能入口隐藏，已有数据保留但不可操作；重新升级后可恢复 |

## 三、系统初始化

**菜单路径**：费用管控 → 系统初始化

系统首次部署后，管理员在此页面完成工作流和资金池配置。**基础版无需配置**，部署完成即可使用。

### 3.1 基础版

基础版采用系统内置默认配置，**无需任何初始化操作**：

| 项目 | 默认行为 |
|------|----------|
| 预算编制审批 | 固定：编制人 → 部门经理审批（单级） |
| 报销审核 | 固定：报销人 → 部门经理审批（单级） |
| 预算调整 | 不支持 |
| 资金池 | 无 |
| 合规引擎 | 固定NORMAL级别 |

> 升级高级版后，「系统初始化」配置功能自动解锁。

### 3.2 高级版初始化

#### 第一步：配置工作流

进入 **系统初始化 → 工作流配置** 页签，可配置三条工作流：

**① 预算编制工作流**

| 操作步骤 | 说明 |
|----------|------|
| 1. 点击「预算编制工作流」卡片的「配置」按钮 | 弹出节点配置窗口 |
| 2. 点击「+ 添加审批节点」 | 支持1~N级 |
| 3. 每级设置：节点名称、审批角色、审批方式 | 角色从系统角色列表选择 |
| 4. 点击「保存」 | 状态为"未部署(DRAFT)" |
| 5. 确认无误后点击「部署」 | 自动生成BPMN流程并部署，状态变为"已部署" |

**推荐配置（2级审批）**：

| 节点顺序 | 节点名称 | 审批角色 | 审批方式 |
|----------|----------|----------|----------|
| 1 | 部门经理审批 | 部门经理 | 单人审批 |
| 2 | 财务复核 | 财务 | 单人审批 |

**② 报销审核工作流** — 推荐配置同上（部门经理 → 财务审核）

**③ 预算调整工作流** — 推荐配置：部门经理 → 财务审批

> ⚠️ 修改配置后需重新点击「部署」才生效。已在审批中的单据不受影响，仍按旧流程走完。
> 
> 💡 不配置也可使用，系统自动使用内置默认流程。

#### 第二步：配置资金池

进入 **系统初始化 → 资金池配置** 页签。高级版仅支持**部门级单层资金池**：

| 操作步骤 | 说明 |
|----------|------|
| 1. 修改「初始额度」 | 默认100,000元，按需调整 |
| 2. 修改「预警阈值」 | 默认80%，超过时推送预警消息 |
| 3. 点击「保存配置」 | 下个预算期间（下月）生效 |

**资金池运作规则**：
- 每月初系统自动为每个部门创建资金池记录；
- 预算调整审批通过时，从资金池扣减分摊金额；
- 可用余额 = 初始额度 - 已分摊金额；
- 余额低于预警阈值时，自动通知部门经理。

### 3.3 企业版初始化

#### 第一步：配置工作流（推荐三级审批）

**预算编制工作流推荐配置（3级）**：

| 节点顺序 | 节点名称 | 审批角色 | 审批方式 |
|----------|----------|----------|----------|
| 1 | 部门领导审批 | 部门经理 | 单人审批 |
| 2 | 分公司领导审批 | 分公司管理员 | 单人审批 |
| 3 | 总公司领导审批 | 总公司管理员 | 单人审批 |

**预算调整工作流推荐配置（3级）**：部门审批 → 分公司审批 → 总公司审批

> 💡 企业版支持**会签模式**：如总公司有多个副总，可将该节点设为「会签」，全部副总通过才流转。

#### 第二步：配置三级资金池

企业版支持 **部门 / 分公司 / 总公司** 三级独立资金池：

| 层级 | 关联角色（默认） | 默认初始额度 | 操作步骤 |
|------|------------------|--------------|----------|
| 部门级 | 部门经理 | 100,000元 | 在页面第一行修改额度和阈值 |
| 分公司级 | 分公司管理员 | 500,000元 | 在页面第二行修改额度和阈值 |
| 总公司级 | 总公司管理员 | 1,000,000元 | 在页面第三行修改额度和阈值 |

配置完成后点击「保存配置」，下一预算期间自动按新配置创建资金池。

**三级分摊规则**：
```
超预算/预算调整申请
    → 第1级：部门资金池补足（足够则直接通过）
    → 第2级：分公司资金池分摊（部门不足时转审）
    → 第3级：总公司资金池兜底（分公司不足时转审）
    → 三级均不足 → 驳回申请
```

## 四、预算编制

### 4.1 基础版操作指南

**菜单路径**：预算编制（左侧菜单）

#### 4.1.1 新建预算编制（编制人员操作）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 点击列表页左上角 **「新增」** 按钮 | 进入3步向导 |
| 2 | **第1步-基础信息**：选择预算月份 | 年度、组织、编制人自动填充（只读） |
| 3 | 点击「下一步」 | 系统自动校验：同部门同月份不可重复创建 |
| 4 | **第2步-科目预算明细**：按Tab填写金额 | 6个Tab：收入类/成本类/费用类/资产类/负债类/权益类 |
| 5 | 参考「上月实绩」列调整预算金额 | 系统自动加载上月报销实际数据作为参考 |
| 6 | 填写完成点击「下一步」 | 右上角实时显示预算总额 |
| 7 | **第3步-确认提交**：核对汇总信息 | 展示各类型小计和预算总额 |
| 8 | 点击 **「完成编制」** | 状态变为"完成编制(Completed)" |

**填写说明**：
- 「预算金额」列：本月计划金额，必填，最小0，保留2位小数；
- 「上月实绩」列：上月实际报销数据，只读参考；
- 「差异金额/差异率」：系统自动计算，无需填写；
- 固定资产类科目需填写「使用年限」（必填）。

#### 4.1.2 提交审核

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在列表中找到状态为"完成编制"的记录 | 只有Completed状态可提交 |
| 2 | 点击 **「提交审核」** 按钮 | 状态变为"待审核(Pending_Review)" |
| 3 | 等待部门经理审批 | 系统自动发送站内通知给部门经理 |

#### 4.1.3 审批操作（部门经理）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 进入 **预算审核** 菜单 | 看到本部门待审核的预算单列表 |
| 2 | 点击记录进入审批详情 | 查看基础信息、科目明细（分Tab）、风控校验结果 |
| 3a | 点击 **「审批通过」**（可填意见） | 基础版单级审批，通过后预算锁定生效 |
| 3b | 点击 **「审批驳回」**（必填原因，5-500字） | 退回编制人，状态变为"已驳回" |

#### 4.1.4 驳回后重新提交

```
已驳回(Rejected) → 点击「修改」进入编辑（直接到第2步）→ 调整金额 → 完成编制(Completed) → 再次提交审核
```

#### 4.1.5 状态说明

| 状态 | 颜色 | 允许的操作 |
|------|------|------------|
| 草稿(Draft) | 灰色 | 编辑、删除、完成编制 |
| 完成编制(Completed) | 蓝色 | 提交审核 |
| 待审核(Pending_Review) | 橙色 | 仅查看（审批人可审批） |
| 审核通过(Approved) | 绿色 | 仅查看，预算锁定 |
| 已驳回(Rejected) | 红色 | 编辑、重新提交 |

### 4.2 高级版增量操作

在基础版全部功能之上，高级版新增：

#### 4.2.1 批量提交审核

| 步骤 | 操作 |
|------|------|
| 1 | 在编制列表勾选多条"完成编制"状态的记录 |
| 2 | 点击列表上方 **「批量提交」** 按钮 |
| 3 | 确认后统一进入审批流程 |

#### 4.2.2 批量审批

| 步骤 | 操作 |
|------|------|
| 1 | 在预算审核列表勾选多条待审核记录 |
| 2 | 点击 **「批量审批」** 按钮 |
| 3 | 确认后统一通过 |

#### 4.2.3 多级审批流程

管理员在「系统初始化」配置多级审批后，预算单提交后按配置的节点逐级流转：
- 第1级审批人通过后，自动流转到第2级；
- 任一级别驳回，统一回退到编制人员；
- 编制人可在列表中查看当前审批到哪一级。

#### 4.2.4 编制期管控与提醒

- 每月26日系统自动推送"编制期开始"提醒（站内消息+邮件）；
- 截止前4小时/1小时发送提醒；
- 超时未编制发送告警通知。

### 4.3 企业版增量操作

在高级版全部功能之上，企业版新增：

#### 4.3.1 固定三级审批

预算单提交后自动按三级流转：

```
编制人提交 → 部门经理审批 → 分公司领导审批 → 总公司领导审批 → 预算生效(Approved)
```

- 审批详情页可查看当前处于哪一级（approval_stage: Dept/Branch/HQ）；
- 任一级别驳回，统一回退到编制人员修改。

#### 4.3.2 打回至部门

分公司/总公司审批人除「通过」「驳回」外，还可使用 **「打回」** 操作：
- 打回后状态变为"待修订(Pending_Revision)"；
- 编制部门收到通知后修改并重新提交；
- 与驳回的区别：打回不记入驳回历史，属于沟通性退回。

#### 4.3.3 超时告警

- 审批超时（配置时限内未处理）自动发送告警；
- 超时记录标记 is_timeout，管理层可在审核列表筛选查看。

#### 4.3.4 AI对话助手

- 在预算编制页面可打开AI对话窗口；
- 支持询问当前预算数据相关问题（AI自动注入当前预算单上下文）；
- 入口：编制详情页右下角AI助手图标。

## 五、费用管控（费用报销）

### 5.1 基础版操作指南

#### 5.1.1 填写报销单（报销人操作）

**菜单路径**：费用管控 → 费用报销（或 报销单管理）

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 点击 **「新增报销单」** | 进入报销单表单页 |
| 2 | 选择 **物资小类**（下拉） | 如：差旅服务、办公用品、IT设备 |
| 3 | 选择 **用途标签**（单选按钮组） | 如：市场活动、日常办公、项目交付 |
| 4 | 系统自动匹配 **预算科目** | 页面展示匹配结果预览（科目名称+当前余额） |
| 5 | 填写报销金额、费用日期、报销年月 | 报销年月(YYYY-MM)对应预算编制期间 |
| 6 | 上传发票附件 | 票据类型：正式发票/收据 |
| 7 | 如为固定资产，勾选并填写 **使用年限** | 固定资产必填使用年限 |
| 8 | 点击 **「保存草稿」** 或直接 **「提交」** | — |

> 💡 用途标签为"项目交付"时，**项目编号为必填项**。

#### 5.1.2 预算校验规则

- 提交时系统自动校验：报销金额 ≤ 对应科目当月可用余额；
- **余额充足**：正常提交，状态变为 SUBMITTED；
- **余额不足**（基础版）：提示预算不足，无法提交，需等待下月预算或联系管理员；
- 审批通过后系统自动扣减预算余额。

#### 5.1.3 报销单审批（部门经理操作）

**菜单路径**：费用管控 → 报销单审批

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 进入报销单审批列表 | 仅显示本部门待审批(SUBMITTED)的报销单 |
| 2 | 点击记录查看详情 | 含报销信息、发票附件、操作时间线 |
| 3a | 点击 **「通过」**（可填审批意见） | 状态→APPROVED，预算自动扣减，通知报销人 |
| 3b | 点击 **「驳回」**（必填原因，5-500字） | 状态→REJECTED，通知报销人 |

#### 5.1.4 驳回后处理

| 步骤 | 操作 |
|------|------|
| 1 | 报销人收到驳回通知，进入报销单列表 |
| 2 | 找到"已驳回"状态的报销单，点击 **「编辑」** |
| 3 | 修改金额或附件后，点击 **「重新提交」** |
| 4 | 状态 REJECTED → SUBMITTED，重新进入审批 |

#### 5.1.5 报销单状态与操作权限

| 状态 | 报销人可操作 | 部门经理可操作 |
|------|-------------|---------------|
| 草稿(DRAFT) | 编辑、提交、删除 | 查看 |
| 已提交(SUBMITTED) | 查看、删除 | 通过、驳回 |
| 已通过(APPROVED) | 查看（只读） | 查看（只读） |
| 已驳回(REJECTED) | 编辑、重新提交、删除 | 查看 |

> **删除规则**：仅已通过(APPROVED)的报销单不可删除，其他状态均可删除。

## 六、预算调整

### 6.1 基础版

基础版**不支持预算调整功能**。预算超支时：
- 系统仅提示余额不足，报销单无法提交；
- 需等待下月预算生效，或联系管理员升级版本。

### 6.2 高级版操作指南

高级版支持**部门级资金池**预算调整。

#### 6.2.1 报销人发起预算调整申请

**触发场景**：提交报销单时预算不足。

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 提交报销单时系统提示"预算不足，缺口¥5,000" | — |
| 2 | 点击 **「申请预算调整」** | 进入申请表单 |
| 3 | 确认物资小类、用途标签（自动带入） | 系统自动匹配目标科目 |
| 4 | 查看预算归属预览：目标科目 + 当前余额 | — |
| 5 | 填写申请金额（默认=缺口金额） | 可调整，但需≥缺口 |
| 6 | 填写调整原因（必填） | 如"紧急采购开发用笔记本" |
| 7 | 点击「提交」 | 自动生成单号 BA-YYYYMMDD-XXX，流转至部门领导 |

#### 6.2.2 部门领导审批

**菜单路径**：费用管控 → 预算调整申请

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 在列表查看待审批申请 | 页面展示：申请人、目标科目、申请金额、调整原因 |
| 2 | 查看本级资金池情况 | 资金池总额 / 已分摊 / 剩余可用 |
| 3a | 点击 **「同意分摊」** | 从部门资金池拨出差额至目标科目，科目余额增加 |
| 3b | 点击 **「驳回」**（必填原因） | 申请退回报销人 |

**分摊计算规则**：分摊金额 = 申请金额 - 当前科目余额（仅补足差额）。

#### 6.2.3 审批通过后

1. 目标科目可用余额实时增加；
2. 报销人收到站内通知"预算调整已通过"；
3. 报销人重新进入报销单，此时余额充足，正常提交即可。

### 6.3 企业版操作指南

企业版支持**三级资金池逐级转审**：部门 → 分公司 → 总公司。

#### 6.3.1 逐级审批流程

```
报销人发起申请（¥5,000）
    │
    ▼
部门领导审批 —— 部门资金池充足？
    │ 是 → 同意分摊 → 通过
    │ 否 ↓
    ▼
部门领导点击「向上级转审」
    │
    ▼
分公司领导审批 —— 分公司资金池充足？
    │ 是 → 同意分摊 → 资金注入部门资金池 → 通过
    │ 否 ↓
    ▼
分公司领导点击「向上级转审」
    │
    ▼
总公司领导审批 —— 总公司资金池充足？
    │ 是 → 同意分摊 → 资金注入分公司资金池 → 通过
    │ 否 → 驳回（各级资金池均已不足）
```

#### 6.3.2 各层级审批操作

| 审批层级 | 页面展示 | 可执行操作 |
|----------|----------|------------|
| 部门领导 | 申请详情 + 部门资金池余额 | 同意分摊 / 驳回 / 向上级转审 |
| 分公司领导 | 申请详情 + 分公司资金池余额 | 同意分摊 / 驳回 / 向上级转审 |
| 总公司领导 | 申请详情 + 总公司资金池余额 | 同意分摊 / 驳回 |

#### 6.3.3 申请单状态说明

| 状态 | 说明 |
|------|------|
| DEPT_APPROVING | 部门审批中 |
| BRANCH_APPROVING | 分公司审批中 |
| HQ_APPROVING | 总公司审批中 |
| APPROVED | 已通过（分摊完成） |
| REJECTED | 已驳回 |

#### 6.3.4 资金池管理页面

**菜单路径**：费用管控 → 资金池管理

页面实时展示各层级资金池：

| 展示字段 | 说明 |
|----------|------|
| 资金池总额 | 初始额度 + 上级注入 |
| 已分摊金额 | 累计已拨出金额 |
| 剩余可用额度 | 总额 - 已分摊 |
| 使用比例 | 超过80%时红色预警 |

> 资金池按月创建，不结转下月。每月初按系统初始化配置的额度重新创建。

## 八、常见问题

### 版本相关

**Q：切换版本后需要重启服务吗？**  
A：不需要。版本切换即时生效，刷新页面即可看到变化。

**Q：降级后数据会丢失吗？**  
A：不会。降级仅隐藏功能入口，所有历史数据完整保留。

**Q：升级后需要重新初始化吗？**  
A：不需要重新部署。升级后新功能入口自动出现，管理员按需配置即可。未配置前使用默认行为。

### 预算编制相关

**Q：同一部门同月可以创建多份预算吗？**  
A：不可以。系统在新建第1步点击"下一步"时自动校验，重复则阻止。

**Q：审批通过后还能修改吗？**  
A：不能。Approved状态预算锁定，所有角色仅可查看。如需调整请走预算调整流程。

**Q：上月实绩数据从哪里来？**  
A：系统自动加载上月已审批通过的报销单实际数据，按科目汇总填入"上月实绩"列。

### 费用报销相关

**Q：提交时提示"预算不足"怎么办？**  
A：三种方式：①等下月预算生效；②高级版+可走超预算审批或发起预算调整申请；③联系管理员。

**Q：报销单被驳回后如何修改？**  
A：在报销单列表找到"已驳回"的记录，点击编辑修改后重新提交即可。

**Q：映射规则匹配不到科目怎么办？**  
A：报销单归入"待分摊成本中心"，系统通知管理员。请在映射规则管理中补充规则。

### 预算调整相关

**Q：预算调整申请通过后，报销单会自动提交吗？**  
A：不会。分摊完成后科目余额增加，报销人需重新进入报销单手动提交。

**Q：资金池不足时会怎样？**  
A：部门不足可转审分公司，分公司不足转审总公司，三级均不足则驳回申请。
