### 1.1 文档目的

本文档是全面预算管理与费用管控系统 V5.4 的详细设计文档，面向 AI Agent 开发场景。文档按照 **Phase→Task→文件→方法** 的粒度组织，每个待实现的功能点都给出了：
- 文件路径与类名
- 方法签名（入参、返回值）

- 依赖关系与实现顺序

        // 预占费用轨预算
        count++;
    }

    for (ContractLedger contract : activeContracts) {

        count++;

    return count;

## 十五、功能开关与版本对照（Agent 开发注意事项）

1. **所有高级版/企业版功能接口**必须添加 `@RequireFeature("对应开关编码")` 注解
2. **前端菜单/按钮**根据 `/system/license/info` 返回的 features 列表动态渲染
3. **基础版固定行为**：合规引擎固定 NORMAL 不可配置、盈利提示固定文案不可编辑、无资金池
4. **代码无分支**：所有版本共用一套代码，差异仅通过 Feature 注解 + 前端 v-if 控制可见性
5. **行业过滤**：所有配置类查询（映射规则/标签/话术/阈值）必须携带 industry_code 条件
