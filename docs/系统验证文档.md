### 1.2 验收标准总则

- P0 功能：通过率必须 **100%**
- P1 功能：通过率 ≥ **95%**
- P2 功能：通过率 ≥ **90%**
- 性能指标：全部达标
- 安全指标：零漏洞
- 版本隔离：功能开关100%有效
