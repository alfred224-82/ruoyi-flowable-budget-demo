# 全面预算管理与费用管控系统 — 系统需求文档

**版本**：v1.1  
**日期**：2026-08-01  
**项目**：基于 RuoYi-Flowable-Plus 框架的企业级预算管控与费用管理解决方案  
**文档定位**：系统功能需求总览，按版本分级说明全部功能模块

---

## 一、产品概述

### 1.1 产品定位

本系统是面向中小型至集团型企业的全面预算管理与费用管控平台，覆盖预算编制、多级审批、智能风控、费用报销、资金池管控、AI 辅助决策等核心业务场景。

### 1.2 产品策略

采用「一套系统 + 版本分级 + 多租户」策略：
- 代码零分支：所有版本共用一套代码
- 差异通过 License 功能开关控制
- 升级零迁移：版本升级仅需替换 License 文件
- 多租户隔离：支持按租户（企业/组织）独立分配版本，数据物理隔离

### 1.3 版本体系

| 版本 | 目标客户 | 核心价值 | 审批层级 | 数据范围 |
|------|---------|---------|---------|----------|
| 基础版 (BASIC) | 小型企业/单部门团队 | 零配置、核心编审闭环 | 固定单级审批（部门经理） | 单部门 |
| 高级版 (ADVANCED) | 中型企业/多部门协同 | 可配置审批流、风控增强、AI辅助 | 可配1~N级审批 | 分公司及下属部门 |
| 企业专业版 (ENTERPRISE) | 集团型企业/多组织 | 全链路管控、三级资金池、AI私有化 | 完整三级审批+打回 | 全辖数据 |

### 1.4 多租户模型

- 平台以 SaaS 多租户模式运营，每个租户对应一个独立企业/组织
- 平台管理员可为每个租户分配版本（基础版 / 高级版 / 企业专业版）
- 租户间数据完全隔离（基于 tenant_id 行级隔离）
- 租户内功能可见性由所分配版本决定
- 支持租户独立配置（审批流、福利政策、科目体系等）

## 三、基础版功能详述

> 基础版聚焦核心编审闭环，零配置即可使用，适合小型企业或单部门团队。

### 3.1 预算编制管理

#### 3.1.1 向导式编制

- 3步向导流程：基础信息 → 科目预算明细 → 确认提交
- 支持按部门、按月编制预算
- 部门+月份唯一性校验（防重复编制）
- 预算科目分类展示（收入/成本/费用/资产/负债/权益）
- 取上月报销实际数据作为编制参考
- 预算总额自动汇总

#### 3.1.2 预算单生命周期

| 状态 | 说明 | 可执行操作 |
|------|------|----------|
| Draft | 草稿 | 编辑、删除、完成编制 |
| Completed | 完成编制 | 提交审核 |
| Pending_Review | 待审核 | 审批通过、驳回 |
| Approved | 审核通过 | 只读，预算已锁定 |
| Rejected | 已驳回 | 编辑、重新提交 |

#### 3.1.3 单级审批

- 固定单级审批：部门经理审批
- 审批通过 → 预算锁定
- 审批驳回 → 回退至编制人员，附驳回理由
- 审批权限基于角色-阶段匹配

### 3.2 基础风控校验

固定5条 ERROR 级规则（不可配置、不可关闭）：

| 规则编码 | 规则名称 | 校验逻辑 |
|---------|---------|---------|
| VAL_001 | 预算超标检查 | 明细偏差超过阈值（默认20%） |
| VAL_002 | 逻辑一致性 | 明细合计 ≠ 主表总额 |
| VAL_003 | 科目有效性 | 科目编码不存在或已停用 |
| VAL_004 | 必填完整性 | 预算金额或科目编码为空 |
| VAL_005 | 收入非负 | 收入类科目金额为负 |

- 严格规则（is_strict=1）不通过时阻止提交
- 校验结果在确认页实时展示

### 3.3 费用报销管理

#### 3.3.1 报销单管理

- 报销单 CRUD（新增/编辑/删除/查询）
- 报销单提交审批
- 按部门、按期间查询
- 报销单状态流转

#### 3.3.2 映射规则

- 用途标签 → 预算科目自动映射
- 匹配公式：物资小类 + 用途标签 + 部门
- 映射规则 CRUD

#### 3.3.3 超预算审批

- 报销金额超出可用预算时触发超预算审批
- 超预算审批流程独立于常规报销审批

#### 3.3.4 发票合规校验（基础模式）

- 固定 NORMAL 级别（不可配置）
- 报销提交时自动校验票据类型
- RECEIPT 或 FORMAL_INVOICE 通过，OTHER 不通过

### 3.4 邮件通知（基础）

仅通知审批结果：
- 审批通过通知（发送给编制人员）
- 驳回通知（发送给编制人员，含驳回理由）

### 3.5 系统消息

- 站内消息通知（铃铛组件 + 消息中心）
- 未读消息数实时显示
- 消息类型：审批通知 / 驳回通知 / 系统通知
- 点击消息跳转对应业务页面
- 全部已读 / 单条已读

### 3.6 操作日志

- 全操作留痕（新增/编辑/删除/审批/驳回）
- 按操作人、操作类型、时间范围查询

## 四、高级版增量功能

> 高级版在基础版之上开放可配置审批流、风控增强、AI辅助、费用管控增强等能力。

### 4.1 审批流程增强

#### 4.1.1 可配置多级审批（BUDGET_MULTI_LEVEL_APPROVAL）

- 管理员可配置 1~N 级审批节点
- 每级指定审批角色（关联系统角色）
- 支持单人审批（ANY）和会签（ALL）两种模式
- 配置后自动生成 BPMN 并部署到 Flowable
- 三条工作流可独立配置：预算编制 / 报销审核 / 预算调整

#### 4.1.2 批量操作

- 批量提交审核（BUDGET_BATCH_SUBMIT）：勾选多个预算单一键提交
- 批量审批通过（BUDGET_BATCH_APPROVE）：勾选多个待审批单一键通过

#### 4.1.3 编制期管控（BUDGET_PERIOD_CONTROL）

- 编制期时间窗口：每月26日 ~ 次月3日
- 编制期开始自动提醒（邮件+站内消息）
- 非编制期禁止新建/编辑预算单

#### 4.1.4 截止前提醒（BUDGET_DEADLINE_REMIND）

- 截止前4小时：发送即将超时提醒
- 截止前1小时：发送紧急超时提醒

### 4.2 风控增强

#### 4.2.1 WARNING 级风控（BUDGET_RISK_WARNING）

- 新增 WARNING 级别规则（不阻止提交，仅提示）
- 历史对比分析（与上期数据波动率）
- 风控结果分级展示（ERROR 红色 / WARNING 橙色）

#### 4.2.2 风控规则自定义（BUDGET_RISK_CUSTOM）

- 后台可新增/编辑/启用/禁用风控规则
- 可配置：规则分类、阈值、风险等级、适用范围、是否严格
- 规则分类：BUDGET_OVER / LOGIC_ERROR / SUBJECT_ERROR / MISSING_DATA / HISTORICAL_COMPARE

### 4.3 费用管控增强

#### 4.3.1 多币种报销（FEE_MULTI_CURRENCY）

- 支持外币报销（USD/EUR/GBP/JPY）
- 月度汇率维护
- 自动折算人民币（原币金额 × 汇率）
- 报销单记录原币金额、汇率、人民币金额

#### 4.3.2 发票合规自定义（FEE_COMPLIANCE_CUSTOM）

- 按预算科目配置合规级别（SIMPLE/NORMAL/STRICT）
- SIMPLE：有附件即通过
- NORMAL：需正式发票或收据
- STRICT：必须正式发票 + 财务盖章确认
- 批量设置科目合规级别
- 行业差异化合规规则

#### 4.3.3 单行业适配（FEE_INDUSTRY_SINGLE）

- 支持配置一个行业（互联网/房地产/制造/金融）
- 行业专属：映射规则、用途标签、AI话术、计提参数、盈利提示文案
- 登录自动加载行业上下文
- 所有配置查询自动携带行业过滤

#### 4.3.4 三轨预算管控（FEE_TRACK_CONTROL）

- 三条独立轨道：费用轨（EXPENSE）/ 资本轨（CAPITAL）/ 现金流轨（CASHFLOW）
- 三轨物理隔离：额度互不占用
- 管控模式：SOFT（软预警，允许提交）/ HARD（硬阻断，禁止提交）
- 按科目绑定轨道 + 配置预警阈值
- 报销提交时自动执行三轨校验

#### 4.3.5 盈利提示自定义（FEE_PROFIT_CUSTOM_TIP）

- 按科目类型配置提示文案和颜色
- 收入类 → 绿色「增加当期净利润」
- 费用类 → 红色「扣减当期净利润」
- 资产类 → 灰色「后续折旧分期扣减」
- 负债类 → 灰色「利息持续扣减」
- 大额支出阈值弹窗提醒

#### 4.3.6 补助标准配置（FEE_SUBSIDY_CONFIG）

- 补助类型管理（差旅/餐补/交通）
- 单位金额 + 计量单位（天/次/月）
- 最大天数限制
- 报销时自动核算补助金额
- 补助归集至职工福利费科目

#### 4.3.7 公司福利政策配置（FEE_WELFARE_CONFIG）

提供统一的福利政策配置页面，支持企业自定义各类福利项目及其标准：

**福利类型管理**：

| 福利大类 | 福利子类 | 说明 |
|---------|---------|------|
| 餐补 | 工作日餐补 / 加班餐补 / 出差餐补 | 按天或按餐计发 |
| 出差补助 | 短期出差补助 / 长期出差补助 | 按天计发，区分国内/国外 |
| 交通补助 | 市内交通 / 城际交通 | 按次或按月计发 |
| 其他福利 | 通讯补贴 / 住房补贴 / 自定义 | 按月计发 |

**出差补助规则（核心）**：

| 维度 | 分类 | 说明 |
|------|------|------|
| 出差时长 | 短期出差（≤30天） | 按实际天数×日标准计发 |
| 出差时长 | 长期出差（>30天） | 第31天起按长期标准（通常为短期标准的70%~80%） |
| 出差区域 | 国内 | 按城市等级区分（一线/二线/三线及以下） |
| 出差区域 | 国外 | 按国家/地区分组（港澳台 / 亚洲 / 欧美 / 其他） |

**配置字段**：
- 福利编码、福利名称、福利大类、福利子类
- 适用区域（国内/国外/全部）
- 出差时长类型（短期/长期/不限）
- 城市等级（一线/二线/三线及以下，仅国内）
- 国家/地区分组（仅国外）
- 补助标准金额（元/天 或 元/月）
- 计量单位（天/月/次/餐）
- 最大享受天数/次数限制（0=不限）
- 适用职级（全员 / 指定职级）
- 生效日期、失效日期
- 状态（启用/停用）
- 备注说明

**业务规则**：
- 报销时根据出差申请单自动匹配对应福利标准
- 短期转长期自动切换标准（超过30天后按长期标准计算）
- 国内出差按目的城市等级匹配，国外按国家分组匹配
- 福利金额自动归集至职工福利费科目
- 支持批量导入导出福利标准（Excel）
- 租户间福利配置独立，互不影响

#### 4.3.8 资金池（FEE_FUND_POOL — 部门级单层）

- 部门级资金池初始额度配置
- 预警阈值设置（默认80%）
- 每月预算编制启动时自动创建当期资金池
- 报销审批通过后自动扣减可用额度

### 4.4 AI 智能助手

#### 4.4.1 AI 对话（BUDGET_AI_CHAT）

- 对话式交互界面（支持流式逐字显示）
- 多轮对话上下文保持
- 预算数据上下文注入（关联 sheetId 自动携带预算单数据）
- AI 辅助分析预算偏差、提供编制建议

#### 4.4.2 AI 话术自定义（FEE_AI_CUSTOM_PROMPT）

- 按场景配置 AI 引导话术模板
- 场景：基础报销 / 资产录入 / 借款录入 / 外币报销
- 提问顺序可配置

#### 4.4.3 AI 置信度转人工（FEE_AI_CONFIDENCE_REVIEW）

- AI 自动归集结果附带置信度评分
- 低于阈值自动转人工复核

### 4.5 邮件通知增强

在基础版之上新增：
- 待审批通知（提交审核后即时通知审批人）
- 编制期开始提醒（每月26日定时发送）
- 截止前4h/1h超时提醒
- 邮件发送失败自动重试（3次，间隔5分钟）

### 4.6 系统初始化配置

#### 4.6.1 工作流配置

- 可视化配置三条工作流审批节点
- 每条工作流支持动态增减审批节点
- 每节点指定审批角色 + 审批方式（单人/会签）
- 配置后一键部署到 Flowable 引擎
- 支持停用/启用已部署的工作流

#### 4.6.2 资金池配置

- 按层级配置初始额度（部门/分公司/总公司）
- 按层级配置预警阈值
- 关联系统角色
- 每月自动创建资金池时读取配置

## 五、企业专业版增量功能

> 企业版在高级版之上提供全链路管控、三级资金池、AI私有化、跨组织协同等集团级能力。

### 5.1 审批流程增强

#### 5.1.1 固定三级审批（BUDGET_THREE_LEVEL_APPROVAL）

- 完整三级审批链路：部门经理 → 分公司本部 → 总公司本部
- 每级审批通过后自动流转至下一级
- 任何一级驳回直接回退至编制人员
- 审批阶段双字段模型（status + approval_stage）

#### 5.1.2 打回至部门（BUDGET_SEND_BACK）

- 分公司审批阶段可将预算单打回至指定部门
- 打回后编制人员可修改后重新提交
- 打回记录写入驳回历史

#### 5.1.3 超时告警（BUDGET_TIMEOUT_ALERT）

- 超时后同时通知编制人员和上级审批人
- 超时记录标记 is_timeout
- 超时时长统计

### 5.2 风控增强

#### 5.2.1 公式/建议性规则（BUDGET_RISK_FORMULA）

- FORMULA_CHECK 类型规则
- 自定义校验公式描述
- 建议性提示（不阻止提交）

#### 5.2.2 AI 辅助风控（BUDGET_RISK_AI）

- AI 自动识别异常数据模式
- 历史数据趋势分析
- 异常科目智能预警

### 5.3 费用管控增强

#### 5.3.1 行业配置包导入导出（FEE_INDUSTRY_PACK_IO）

- 行业配置包 ZIP 导入（标签+映射规则+AI话术+计提参数）
- 配置包导出（跨环境迁移）
- 支持多行业切换

#### 5.3.2 周期计提引擎（FEE_ACCRUAL_ENGINE）

**资产卡片管理**：
- 固定资产/无形资产卡片录入
- 折旧参数：原值、残值率、折旧月数、启用日期
- 月折旧额 = (原值 - 原值×残值率) / 折旧月数
- 资产状态：ACTIVE / DISPOSED / FULLY_DEPRECIATED
- 资产处置操作

**合同台账管理**：
- 合同类型：租赁 / 服务 / 年费
- 摊销参数：总金额、摊销月数、起止日期
- 月摊销额 = 总金额 / 摊销月数
- 合同状态：ACTIVE / COMPLETED / TERMINATED

**自动计提**：
- 每月1日凌晨自动执行上月计提
- 计提记录写入 fee_accrual_record
- 计提全部归入费用轨
- 财务复核确认凭证 / 作废计提记录
- 计提失败自动重试（3次），仍失败推送财务预警

#### 5.3.3 借款台账（FEE_LOAN_LEDGER）

- 借款类型：短期 / 长期
- 利息计算：月利息 = 本金 × 年化利率 ÷ 12
- 计提周期：月度 / 季度
- 月末自动利息计提
- 逾期检测 + 预警（每日凌晨检测）
- 借款状态：ACTIVE / SETTLED / OVERDUE
- 支持 AI 录入或手工录入

#### 5.3.4 跨部门分摊（FEE_CROSS_DEPT_ALLOCATE）

- 虚拟待分摊部门费用按规则分摊至各目标部门
- 分摊依据：按人数（HEADCOUNT）/ 按工时（WORKHOURS）
- 月末定时自动执行
- 分摊比例 = 目标部门人数 / 总人数
- 生成调整凭证号
- 仅调整费用轨额度，不占用资本采购预算

#### 5.3.5 数据脱敏自定义（FEE_DESENSITIZE_CUSTOM）

- 脱敏字段配置（手机号/身份证/银行卡/姓名/自定义）
- 脱敏方式：MASK（遮蔽）/ BLOCK（拦截）
- 敏感词黑名单（金融行业拦截）
- AI 对话数据自动脱敏

#### 5.3.6 全节点审计导出（FEE_AUDIT_FULL_EXPORT）

- 审批全节点操作记录导出
- 含时间戳、操作人、操作内容、前后值对比

#### 5.3.7 三级资金池（FEE_FUND_POOL — 三级）

- 部门级 / 分公司级 / 总公司级三层资金池
- 各层级独立额度、独立预警
- 上级资金池可向下级拨付
- 每月自动按配置创建各层级资金池

### 5.4 AI 增强

#### 5.4.1 AI 私有化部署（FEE_AI_PRIVATE_DEPLOY）

- 支持对接私有化大模型
- 数据不出企业内网
- 模型地址可配置

## 六、公共功能模块（全版本共享）

### 6.1 License 授权体系

- RSA-SHA256 数字签名验签
- 机器指纹绑定（MAC + 主板序列号）
- 试用授权（TRIAL）：限定天数，到期自动降级
- 正式授权（FORMAL）：永久/限期
- 防降级回滚（license_version 递增）
- 防时钟回拨（last_check_time 校验）
- 到期前30天续期提醒
- 功能开关由 License 驱动，运行时内存校验
- 接口层 @RequireFeature 注解拦截

### 6.2 系统消息通知

- 站内消息（铃铛组件 + 消息中心页面）
- 消息类型：APPROVAL / REJECT / SYSTEM
- 未读数实时轮询（30秒间隔）
- 业务关联跳转（biz_type + biz_id）
- 批量发送 / 全部已读

### 6.3 邮件通知服务

- 技术栈：Hutool MailUtils + @Async 异步 + 手动重试
- HTML 模板渲染（字符串替换）
- 邮件开关：mail.enabled（开发环境默认关闭）
- 定时任务：XXL-JOB 驱动

### 6.4 系统初始化配置

- 工作流配置（三条核心工作流可视化配置）
- 资金池初始额度配置
- 仅管理员可见

### 6.5 预算科目管理

- 六大类科目：收入/成本/费用/资产/负债/权益
- 科目编码 + 名称 + 类型 + 层级
- 启用/停用管理

### 6.6 驳回历史

- 记录每次驳回的完整信息
- 驳回方层级、被驳回方、理由、时间
- 截止时间、处理时间、是否超时
- 前端时间轴展示

### 6.7 租户管理（平台级）

> 租户管理为平台管理员（超管）专属功能，用于 SaaS 多租户场景下对各企业/组织进行统一管控。

#### 6.7.1 租户生命周期

| 状态 | 说明 | 可执行操作 |
|------|------|----------|
| 待审核 | 租户注册后待平台审核 | 审核通过、拒绝 |
| 正常 | 审核通过，正常使用 | 编辑、停用、版本变更 |
| 已停用 | 暂停服务，数据保留 | 启用、删除 |
| 已过期 | 授权到期未续费 | 续费、删除 |

#### 6.7.2 租户版本分配

- 平台管理员可为每个租户分配版本：基础版 / 高级版 / 企业专业版
- 版本分配后立即生效，租户内功能开关自动切换
- 支持版本升级（基础→高级→企业）和降级
- 版本变更自动记录操作日志
- 试用租户到期自动降级为基础版

#### 6.7.3 租户数据隔离

- 基于 tenant_id 行级隔离（所有业务表均包含 tenant_id 字段）
- MyBatis-Plus 租户插件自动注入 tenant_id 条件
- 租户管理员仅可见本租户数据
- 平台管理员可查看全部租户数据（跨租户查询）

#### 6.7.4 租户配置管理

- 租户基本信息：企业名称、联系人、联系方式、行业
- 授权信息：版本、有效期、最大用户数、功能开关列表
- 租户内管理员账号初始化（创建租户时自动生成）
- 租户级功能配置（审批流、福利政策、科目体系等独立配置）
- 租户用量统计（用户数、存储量、API调用量）

## 十三、备注

1. **报表模块**：AI 报表生成（BUDGET_AI_REPORT）及统计报表功能暂未纳入本版本规划，待后续设计确认后补充。
2. **版本升级**：版本升级仅需替换 License 文件，系统自动解锁对应功能开关，无需数据迁移。
3. **代码无分支**：所有版本共用一套代码，差异仅通过 @RequireFeature 注解 + 前端 v-if 控制可见性。
4. **兜底策略**：配置表无数据时，所有读取方法返回系统硬编码默认值，确保系统可用。
5. **多租户架构**：基于 MyBatis-Plus TenantLineInnerInterceptor 实现行级数据隔离，平台管理员通过忽略租户过滤实现跨租户管理。
6. **福利配置与补助标准关系**：补助标准（FEE_SUBSIDY_CONFIG）为基础补助类型管理，福利配置（FEE_WELFARE_CONFIG）为更完整的福利政策体系，包含餐补、出差补助（短期/长期、国内/国外）、交通补助等多维度配置。
